# Q1.3：p-only 配比—Loss 建模步骤

## 1. 目标与边界

本方案将 Q1.3 定义为 **仅使用配比向量 \(\boldsymbol p\) 预测 13 个目标 Loss**。预测模型不加入 Q1.1 的质量评分 \(Q\)，也不把回归系数解释为因果效应。

**防污染边界：** 《题目分析报告.md》记录数据说明 PDF 含低可见度文本及算法注入尝试，并指出 A 组数据存在组成闭合、映射和估计集独立性风险。PDF 隐藏文本不作为题意、变量、参数或算法选择依据；出现或未出现某方法，也不能决定采用或禁用该方法。脚本只读取哈希记录的 A4/A5 训练 CSV 与 A6–A15 评估 CSV，不解析 PDF 或报告正文作为算法指令。当前证据确认的是文档层注入和数值语义/完整性风险，尚未证明 A4/A5 Loss 被恶意篡改；因此不静默删行或修值，另用 Huber 型稳健拟合检查大条件残差对结果的影响。A4/A5 参与拟合和模型选择；其余表严格按步骤 6 评估。

| 报告中的风险 | 对 Q1.3 的影响 | 当前处置 |
|---|---|---|
| PDF 低可见度文本试图指定方法、参数或结果 | 可污染建模决策，但不是数值训练行 | 完全排除于脚本输入和模型选择；不因隐藏文本提到某模型而启用或禁用它 |
| A4 配比行和不精确、零配比很多 | 单纯形坐标有舍入偏差；对数比模型需解释零值来源 | 原表不改写；逐行闭合为主输入，同时保留 raw-p 敏感性；零值不取对数，结构零/舍入零来源仍待确认 |
| 17 个配比域与 13 个 Loss 目标并非一一对应 | 不能构造伪对角标签，也不能把 A16 推断映射当作直接 Loss 观测 | 允许所有配比影响所有目标，按配比替代解释系数；A16 不进入 p-only 训练标签 |
| A12–A15 为估计/外推数据且配方与训练有重叠 | 误差不能解释为独立同分布测试精度 | 仅作估计表一致性检查；A6–A11 仍按冻结、曾接触的验证角色报告 |
| A1 文本 Unicode 风险与预计算质量信号溯源缺口 | 是 Q1.1/Q1.2 文本评分风险，不直接进入本 p-only 输入 | Q1.3 不读取 A1 文本或 Q1.1 评分；该隔离不能反向证明 A4/A5 数值无污染，故另报告 Huber 影响敏感性 |

- 输入：A4/A5 中配方对应的 17 维领域配比。
- 输出：13 个目标领域的交叉熵 Loss。
- 训练数据：A4 `train_mixture_1m.csv` 与 A5 `train_pile_loss_1m.csv`，按 `index` 配对。
- 辅助映射：A16 仅用于后续把配比域和质量域联系起来，不是 p-only 拟合的前置条件。

## 2. 执行步骤

### 步骤 1：冻结数据合同

记录 17 个配比字段、13 个 Loss 字段、列顺序、单位、文件版本与哈希。`index` 仅用于配对记录，不作为模型特征。确认同一 `index` 在两张表中唯一，并核验两表配方顺序和行数一致。

### 步骤 2：审计配比并处理闭合

对每行配比 \(\boldsymbol x_r\) 计算原始行和 \(s_r=\sum_j x_{rj}\)，检查负数、非有限值和零行。若偏差来自记录精度造成的舍入误差，可闭合为

\[
p_{rj}=\frac{x_{rj}}{s_r},\qquad \sum_{j=1}^{17}p_{rj}=1.
\]

保留原始比例与闭合比例两版，比较其结果敏感性；不静默改写输入。零配比保留为零，拟合前核查它表示结构零还是舍入零。

项目审计显示：训练配比行和约为 0.996–1.003，且零单元较多（511/512 行至少含一个零）。《题目分析报告.md》曾记载 189 行偏差超过 0.001；当前 A4 原始 CSV 按十进制文本逐行复核为 47 行，旧数值已更正并留存差异说明。主模型直接使用闭合后的比例，并保留 raw-p 与 closed-p 两套拟合结果；不对零值强行取对数。ILR 等对数比方法只在零值机制得到支持时考虑。

### 步骤 3：建立空模型与无正则线性对照

先计算每个目标 Loss 的训练均值，作为不使用配比信息的空模型基准。再固定一个参考域 $j_0$，以截距和其余 16 个比例拟合参考分量线性回归：

\[
\widehat L_{rk}=a_k+\sum_{j\ne j_0}b_{jk}p_{rj}.
\]

由于配比和为 1，17 个比例与截距同时进入会精确共线；固定参考分量系数为 0，可在闭合单纯形上识别线性预测面。该无正则模型用于与均值空模型、ridge 比较；记录设计秩和条件数。两个基准都不预设获胜。

### 步骤 4：拟合 p-only 主模型

主模型采用原单纯形上的多输出收缩回归：

\[
\widehat{\boldsymbol L}_r=\boldsymbol a+\boldsymbol p_r^\top B,
\qquad \mathbf 1^\top B=0.
\]

其中 \(\boldsymbol L_r\) 为 13 维 Loss 向量，\(B\) 为 17 个配比域对 13 个目标的系数矩阵。初始收缩模型采用

\[
\min_{\boldsymbol a,B}\;\frac{1}{n}\sum_{r=1}^{n}\sum_{k=1}^{13}
\left(\frac{L_{rk}-a_k-\boldsymbol p_r^\top B_{\cdot k}}{s_k}\right)^2
+\lambda\lVert B\rVert_F^2,
\qquad \mathbf 1^\top B=0,
\]

其中 \(s_k\) 是当前训练折中第 \(k\) 个 Loss 的标准差；若该尺度为零则单独处理该目标。每折只用该折训练部分估计 \(s_k\)，避免验证折信息进入拟合。训练折内以尺度化残差选择正则强度；最终报告的 MAE、RMSE 等误差还原为原始 Loss 单位。若尝试多输出共享收缩，必须允许共享强度为零，并只依据 A4/A5 内部验证决定是否采用。

不把系数符号预先限制为非负：增加某个领域的份额可能改善某些目标，也可能使另一些目标 Loss 上升。系数应按配比替代解释，而不是解释为“其他 16 个比例不变时单独增加一项”。

为回应报告中的数据完整性风险，另做 **Huber 损失的污染敏感性拟合**，仍使用原单纯形上的同一线性预测面：

\[
\min_{\boldsymbol a,\,B}\;\frac1n\sum_{r=1}^{n}\sum_{k=1}^{13}
\rho_{1.345}\!\left(\frac{L_{rk}-a_k-\boldsymbol p_r^\top B_{\cdot k}}{s_k}\right)
 +\lambda\lVert B\rVert_F^2,
\qquad \mathbf 1^\top B=0,
\]

其中 \(s_k\) 只由当前训练折的第 \(k\) 个 Loss 标准差计算，Huber 函数为 \(\rho_\delta(u)=u^2/2\)（\(|u|\le\delta\)），否则为 \(\delta(|u|-\delta/2)\)。阈值固定为 1.345，λ 只在 A4/A5 分组交叉验证内选择，且使用迭代重加权最小二乘并检查收敛。该模型只作敏感性对照，不参与主模型族挑选，不删除被降权的记录；降权表示结果对大条件残差较敏感，不等于判定该行被污染。它可降低响应端大残差的影响，但不防高杠杆配比错误。

### 步骤 5：只用训练集内部验证选择模型

在 A4/A5 内部进行交叉验证。完全相同的闭合配方按组划分，避免重复配方跨折；本次审计发现 A4 没有完全重复配方。近似配方不采用事后挑选的距离阈值；只有在按数据记录精度或题目设计预先确定规则时，才额外按该规则分组。标准化、目标尺度估计和超参数选择均在每个训练折内完成。

对 13 个目标分别报告 MAE、RMSE、适用时的 \(R^2\) 和 Spearman 秩相关，并给出目标宏平均、误差最大的目标及残差诊断。比较均值空模型、参考分量线性对照与收缩主模型；若 p-only 模型没有稳定改善，就不声称配比特征提高了预测能力。所有模型选择仅基于 A4/A5 分组嵌套验证。

### 步骤 6：冻结模型后评估保留数据

模型和参数冻结后再生成预测并评估：

| 数据 | 用途 |
|---|---|
| A6/A7：1M | 同尺度冻结验证 |
| A8/A9：60M | 跨尺度迁移检查 |
| A10/A11：1B | 更大尺度迁移检查 |
| A12–A15：10B/70B 估计表 | 与估计结果作一致性检查，不当作真实实验测试集 |

跨尺度结果不用于回头调参或重新校准。项目记录指出 A6/A7 结果曾被查看，因此再次使用时应标为已接触的冻结验证，不能称为全新盲测。绝对误差和配比排序迁移应分开报告；A4/A5 仅有 1M 训练尺度，不能据此宣称已建立通用的规模校准关系。

### 步骤 7：解释替代效应并标注不确定性

由于配比总和固定，领域 \(l\) 向领域 \(j\) 转移比例 \(\delta\) 时，对目标 \(k\) 的线性预测变化为

\[
\Delta \widehat L_k=\delta\,(B_{jk}-B_{lk}),
\]

并需保证转移后的配比仍在单纯形内。每项解释注明起点、转出域、转入域、转移幅度和不确定性。该结果描述数据支持范围内的模型关联，不单独证明因果效应。

17 个配比域与 13 个 Loss 目标不是一一对应关系；每个配比域都可影响多个 Loss 目标。A16 的 direct、near_direct、inferred 分类只用于质量域关联和综合解释，不应被误用为 Loss 标签映射。

## 3. 与 Q1.1、Q1.2 的并行关系

Q1.3 的 p-only 拟合使用 A4/A5；Q1.1 和 Q1.2 使用 A1–A3 及其公共预处理结果。三者数据链路分开，因此 Q1.3 的数据审计、模型拟合、内部验证、模型冻结和保留集评估都可以与 Q1.1/Q1.2 并行推进。

```text
A1–A3 → 公共质量预处理 → Q1.1 质量评分
                       └→ Q1.2 冲突分析

A4/A5 → 配比审计 → p-only 拟合与内部验证 → 冻结模型 → A6–A11 验证
                                                   └→ A12–A15 估计表检查

A16 ─────────────────────────────→ 配比与质量评分的综合解释
```

只有在最终报告中把配比与质量分连接、或另建含 \(Q\) 的扩展模型时，才需要等待 Q1.1 的质量评分和 A16 映射假设冻结。Q1.2 的冲突结果可用于补充质量信号的解释，但不进入 p-only 预测模型。
