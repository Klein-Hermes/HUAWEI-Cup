- **Q1：带限制冻结完成。** 操作主 Q 为 `q_huber`，版本 `Q1-q_huber-v1`；`q_equal` 是敏感性分。负责人选择不等同于人工评分判出胜者。Q1 冻结审计记录了机器翻译辅助评审、A2/A3 映射及七个字段单位等解释限制。
- **Q3 质量成本基线：**采用 A1 七个来源域正式 q_huber 域分的等权宏平均 (Q_0=0.4984781048)；对应 95% 区间为 [0.496567, 0.500427]。这是全局基准，不代表 B1/Pythia 配方的实测混合质量。`q_equal` 对应宏平均 0.4962230100，只用于敏感性对照。
- **Q2：**B1 上的经典 `Loss=f(N,D)` M0 已拟合。B1 有 8 个实际参数规模和共同的 147 个训练 Token 检查点，可在这 1,176 个观测组合里做预算筛选。该结果属于 B1 内参考前沿。
- **Q2 的完整 Q/p 响应仍未就绪。** B1–B5 已核验并连接到 Loss 的数值配比向量为 0，p Gate 为 FAIL；当前不能对配比或质量对 Loss 的独立效应作经验优化。
- **C7：**45 条模型架构上下文记录审计通过，形成 5 种离散长度。`max_position_embeddings` 是架构支持上限，不一定等于题目实际部署窗口。

## 现在可推进的分支

在正式 q_huber 基线下固定 (Q=Q_0)，此时质量增量成本 (C_Q=0)。对每一个预算与 C7 上下文长度，筛选满足

\[
C_{\mathrm{train}}+C_{\mathrm{attn}}\le C
\]

的 B1 实际观测 ((N,D)) 组合，并依据冻结的 Q2 M0 预测 Loss 选取最优网格点。归档配置、预测/实测 Loss、成本分解、预算利用率和候选数。该工作回答“在现有 B1 M0 支路和观测支持范围内，预算怎样对应 N/D 参考配置”，不估计 Q/p 效应，也不称为完整 Q3 联合最优解。
