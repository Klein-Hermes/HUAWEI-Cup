# Q3 本轮可识别结果包 rev2（2026-09-25）

本版本在既有 T1/M3/M4、T2、T3、T4 与预算覆盖分析上，新增 M0 函数形式敏感性和整轨迹留一决策分析。结论仍限于固定 Q₀、冻结 M0、B1 当前观测 N/D 支持域及明确标注的 T4 条件敏感性。完整经验 Q/p 联合优化仍未识别；本包不是完整 Q3 联合最优结果，也不是竞赛论文提交包。rev2 独立范围 P2 通过后生成最终回执与哈希清单。

## 入口

- `q3_final_report.md`：本轮结果报告，含函数形式敏感性汇总。
- `q3_master_table.csv`：按预算×上下文键整合的 15 行结果总表；函数形式比较单独保留，不混入 M0 主表。
- `figure_manifest.csv`、`table_manifest.csv`：包内图件、表格路径与 SHA-256。
- `reproduction_manifest.md`：源命令、环境、哈希和复现顺序。
- `frozen_numbers.json`：由源 CSV 直接汇总的锁定数字。
- `scope_decision_ledger.md`：本轮范围与修订记录。
- `QA/P2_independent_release_receipt.md`：本版本独立范围 P2 复核回执；候选生成时为待复核状态。
- `QA/`：限定范围的完整性、一致性、可复现性和独立复核记录。

## 分区

- `01_fixed/`：固定 Q 主结果、成本/预算审计、支持表和 T1 图件。
- `02_robustness/T2/`、`02_robustness/T3/`：近优/Pareto/边际收益、Bootstrap 稳健性和切换结果。
- `02_robustness/model_form_sensitivity/`：M0 形式比较、8 折整轨迹留一明细、结果报告与任务级 manifest。
- `03_conditional/`：条件 βQ 阈值、区间结果和图件。
- `code_sources/`：项目内生成/整理这些产物的脚本快照。

既有 rev1 冻结包保持不变。复现需要在项目根目录使用清单中的命令，并保留 Q1/Q2 上游输入文件。快照保存了直接用于核对和解释的结果文件，但不复制完整 Q1/Q2 原始数据集。

## 新增：预算饱和与有限网格切换

本快照新增固定 Q₀/M0 下的预算覆盖比例、当前 1,176 点支持域饱和预算、完整离散下包络切换事件及正式预算端点对照。详见 01_fixed/预算饱和与有限网格切换/ 和报告第 7 图。该增补仍限于 B1 实测支持网格。

## 新增：M0 函数形式与整轨迹留一敏感性

本 rev2 快照新增固定 Q₀ 下的 8 折整轨迹留一验证、两种预先限定的函数约束、3,528 条留出预测和 360 个折内预算×上下文选点。明细见 02_robustness/model_form_sensitivity/。该敏感性分析不扩展 Bootstrap、不纳入 p/Q 响应，最高预算结论仍限于当前 B1 支持域边界。
