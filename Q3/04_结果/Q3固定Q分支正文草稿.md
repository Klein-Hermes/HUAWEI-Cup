## 固定质量基线下的预算参考配置

### 模型与可行域

Q1 已将操作质量主接口冻结为 `Q1-q_huber-v1`。本节使用 A1 七个来源域的等权宏平均作为成本参考基线，记为 $Q_0=0.4984781048$（95% 区间为 [0.4965674432, 0.5004265176]）。该值是冻结接口的域宏平均，不是 B1 训练配方混合质量的直接测量。另以 `q_equal` 宏平均 0.4962230100 作独立口径敏感性比较。

设 $N$ 和 $D$ 分别为模型参数数与训练 Token 数，C7 架构上下文上限记为 $L_{ctx}$。按题面算力代理公式，

$$
C_{train}=6ND,\qquad C_Q=D[g(Q)-g(Q_0)]_+,\qquad C_{attn}=2\times10^{-4}NDL_{ctx},
$$

并要求 $C_{train}+C_Q+C_{attn}\le C$。主分析固定 $Q=Q_0$，因此 $C_Q=0$；本节不估计质量变化对验证 Loss 的影响，也不把配比 $p$ 作为决策变量。

候选域限定为 Q2 B1 的 1,176 个实测 $(N,D)$ 组合（8 个参数规模与 147 个共同数据量检查点）。对 3 档预算 $10^{19},10^{22},10^{24}$ FLOPs 和 5 档 C7 上下文长度 2,048、4,096、8,192、32,768、131,072 tokens，先合成 $M3$ 实测支持标记与 $M4$ 预算标记，再在最终可行点中最小化 Q2 M0 预测验证 Loss。M0 预测来自 B1 内样本拟合，故结果是受限参考配置，不是外部验证或完整 Q3 联合最优。

### Bootstrap 稳定性与离散情景变化

将 Q2 已有的 1,000 次 B1 轨迹级 cluster Bootstrap 拟合参数传播到 15 个情景，并在每次复本中重新选择可行网格点。15 个情景的原始 M0 选点重选率均为 100%；因此所选 $N_B,D_B$ 的 95% 区间均退化为单点。该结果只说明既定 M0 形式、8 条 B1 轨迹和当前离散支持网格内的参数传播稳定性，不覆盖模型形式误差、外部迁移或支持域之外行为。

为直接判断预算跨档后最优策略是否改变，定义情景 $(C,L_{ctx})$ 下的离散最优策略为

$$
\mathbf{s}^{*}(C,L_{ctx})=(N^{*}(C,L_{ctx}),D^{*}(C,L_{ctx})),
$$

其中 $(N^{*},D^{*})$ 是在最终可行的 B1 网格点上使冻结 M0 预测 Loss 最小的组合；并列时按成本、$N$、$D$ 和 run ID 顺序确定唯一选点。对固定 $L_{ctx}$，随着预算增加，有限候选集的精确转移点定义为 $\tau$ 左右最优网格点不同的候选成本阈值，即

$$
\mathcal{T}(L_{ctx})=\left\{\tau:\mathbf{s}^{*}(\tau^{-},L_{ctx})\ne\mathbf{s}^{*}(\tau^{+},L_{ctx})\right\}.
$$

这一定义在有限网格上作精确枚举，不插值到未观测的 $(N,D)$ 点，也不使用连续优化器的 KKT 活跃集。对相邻正式预算 $C_a,C_b$，再在同一 Bootstrap 复本 $r$ 中分别重选两个情景；若两次选中的 $(N^{*},D^{*})$ 不同则记为一次配置转移。设 $B=1000$，定义配对转移频率

$$
\widehat{\pi}_{ab}(L_{ctx})=\frac{1}{B}\sum_{r=1}^{B}\mathbf{1}\!\left[\mathbf{s}^{*}_{r}(C_a,L_{ctx})\ne\mathbf{s}^{*}_{r}(C_b,L_{ctx})\right].
$$

将 $\widehat{\pi}_{ab}\ge 0.95$ 作为本研究的“稳健离散策略转移”判据。训练与注意力成本份额另以份额向量总变差是否非零判断，且采用同一 95% 配对频率门槛，避免把配置改变和成本构成改变混为一谈。

| 上下文 $L_{ctx}$（tokens） | $10^{19}\to10^{22}$ 区间内切换数 | $10^{22}\to10^{24}$ 区间内切换数 | 两端最优配置是否不同 |
|---:|---:|---:|:---:|
| 2,048 | 274 | 85 | 是 |
| 4,096 | 267 | 92 | 是 |
| 8,192 | 257 | 103 | 是 |
| 32,768 | 224 | 138 | 是 |
| 131,072 | 145 | 221 | 是 |

在五种上下文下，精确有限网格枚举的正式预算端点对均改变选点。对应的 Bootstrap 配对检验中，预算相邻比较 10/10 对均达到该 N/D 转移判据。因此，在固定 $Q=Q_0$、冻结 M0 和 B1 实测候选网格内，预算由 $10^{19}$ 升至 $10^{22}$ FLOPs、以及由 $10^{22}$ 升至 $10^{24}$ FLOPs 时，最优参数规模—训练数据量组合均发生稳健的离散改变。与此同时，预算相邻比较中成本份额转移为 0/10：本模型证据支持 N/D 配置策略改变，不支持训练/注意力成本构成随预算跨档而改变。将上下文变化一并纳入时，22 对相邻情景中 17 对达到 N/D 转移判据，12 对达到成本构成转移判据；后者集中在上下文变化的 12/12 对。完整预算轴扫描共记录 1,865 个下包络事件，其中包括五种上下文各自的首个可行最优点；扣除这五个起点后，每种上下文有 372 次后续配置切换。完整事件范围与正式预算区间切换数见预算扫描结果表。

上述 95% 是配对 Bootstrap 稳定性判据，不是预算的连续临界点检验。1,000 次重抽样来自 8 条独立 B1 轨迹，故应视为当前样本支持域内的稳定性证据，而非 1,000 个独立实验。该转移频率只在冻结 M0 形式下计算。有限的函数形式敏感性分析中，去掉损失下限的形式改变了 15 个正式预算—上下文全样本选点中的 9 个，共享指数形式改变了 1 个；尚未在这两种替代形式下重算 22 对 Bootstrap 转移。因此本结论不代表经过模型形式平均的转移证据，只适用于冻结 M0、固定 $Q_0$ 和有限 B1 网格；它不识别 $Q/p$ 的作用、不代表支持域外行为，也不等于完整 Q3 联合模型下的结构转移结论。

### G2：有限支持域预算限制状态转换

题目要求判断预算跨量级时最优策略是否发生质的变化。相邻预算下的 N/D 选点变化本身只说明离散配置切换，不能直接当作结构性转移。本节在固定 $Q=Q_0$、冻结 M0 与 B1 的 1,176 个实测候选点内，另外识别预算是否改变了最优解的限制来源。

令 $G=\{(n_j,d_j)\}_{j=1}^{1176}$，其中 $n_j=N_j/10^9$、$d_j=D_j/10^9$ 使用 B1 的十亿参数和十亿 Token 单位。对第 $b$ 个 Q2 参数 Bootstrap 复本，定义全支持域无预算最优点
\[
j_b^*=\arg\min_{j\in G}\left(E_b+A_bn_j^{-\alpha_b}+B_bd_j^{-\beta_b}\right),
\]
并令
\[
a_b(C,L)=\mathbf{1}\{C_{j_b^*}(L)>C\},\qquad
C_j(L)=6N_jD_j+2\times10^{-4}N_jD_jL,
\]
其中成本公式的 $N_j,D_j$ 换算为实际参数数和 Token 数。$a_b=1$ 表示预算排除了全支持域的无预算最优点，预算限制了有限支持域最优解；$a_b=0$ 表示该点可行，解受当前实测支持域限制。若相邻预算间的配对状态转换率至少为 95%，则判为有限网格预算限制状态转换。Bootstrap 的 $A,\alpha,B,\beta$ 在全部 1,000 个复本中均为正，且候选网格含唯一联合最大 $(N,D)$ 点，因此每个复本的无预算最优点唯一，状态阈值为 $C_{\mathrm{sat}}(L)=\max_j C_j(L)$。高预算选点命中最大支持点只用作一致性校验，不重复作为转移证据。

|---:|---:|---:|---:|
| 2,048 | $2.30006\times10^{22}$ | 0/1,000；1,000/1,000 | 1,000/1,000；1,000/1,000 |
| 4,096 | $2.44705\times10^{22}$ | 0/1,000；1,000/1,000 | 1,000/1,000；1,000/1,000 |
| 8,192 | $2.74101\times10^{22}$ | 0/1,000；1,000/1,000 | 1,000/1,000；1,000/1,000 |
| 32,768 | $4.50482\times10^{22}$ | 0/1,000；1,000/1,000 | 1,000/1,000；1,000/1,000 |

因此，对题目跨量级预算作出明确判定：五个上下文的低→中预算区间均未发生预算限制状态转换，尽管 N/D 配置在 1,000/1,000 个复本中改变；五个上下文的中→高预算区间均从状态 1 转为 0，达到结构性转移判据。十个预算相邻比较的成本份额变化均为 0/1,000。这里的 1,000/1,000 是参数 Bootstrap 集合中的稳定性结果，不是 1,000 个独立训练实验，也不涵盖模型形式误差、支持域外行为或 Q/p 响应。

### 成本与 Q₀ 敏感性

固定 $Q=Q_0$ 时质量成本份额为零，选点成本由训练与注意力项构成。按题面三种 $g(Q)$ 计算的增量成本曲线说明达到给定质量目标的算力代理成本规模；例如在 B1 最大数据量支持点、目标 $Q=1$ 时，`q_huber` 点值基线下 exponential、power4、logarithmic 三种形式分别约为 $1.1502\times10^{21}$、$1.4069\times10^{21}$ 和 $3.6508\times10^{20}$ FLOPs。这些公式成本不提供质量收益估计。

将基线切换到 `q_equal` 后，固定自身 $Q_0$ 的 $M0$ 目标和预算可行集不变：$C_Q=0$，且现有 M0 不包含 Q/p 对 Loss 的响应项。因此 15 个情景的 N/D 选择与 M0 预测 Loss 均不变。该对照只是当前模型接口下的基线敏感性检查，不能解释为 Q 对 Loss 的经验效应。

### M3/M4/M1 成本与掩码独立核验

对 1,176 个 B1 点、5 个上下文和 3 档预算进行独立成本复算，得到 5,880 行成本网格和 17,640 行预算可行掩码核验。输入单位换算、成本恒等式、M4 成本/预算字段、M3 支持连接及 M0/M1 选点对照均通过：成本恒等式失败 0，M3 键与 N/D 对齐失败 0，M4 成本与掩码一致 17,640/17,640，M0/M1 选点与可行性标记一致 15/15；11/11 条件单调性检查和 10/10 预算嵌套检查通过。复算结论只确认当前文件、口径与连接关系一致，不为 M3 支持分类或 M0 预测增加新的经验识别。

## 本节结论边界

本节对问题三的结构转移作出范围受限的明确判断：在固定 $Q=Q_0$、冻结 M0 与 B1 实测 N/D 网格上，低→中预算发生稳健 N/D 配置切换但预算限制状态不变；中→高预算在五个上下文下均发生有限网格预算限制状态转换，且成本份额构成没有改变。该判断完成了当前固定-Q分支可识别的 G2 判定。Q2 的 B 侧配比 $p$ 仍缺乏可审计且可连接到 Loss 的独立变化，独立于 $p$ 的 Q 变化证据也未建立。因此本节不声称已经识别 Q/p 对 Loss 的独立效应，不估计配比向量，不给出完整 Q/p 联合最优，也不把有限支持域结论外推到连续或更大规模。完整 Q/p 联合优化仍受这些 Q2 证据门槛限制。
