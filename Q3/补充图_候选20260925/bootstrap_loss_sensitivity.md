# 图表契约：Bootstrap Loss 敏感性区间

- **核心结论：** 15 个固定预算—上下文情景的固定形式 M0 预测 Loss 中位数及参数 Bootstrap 百分位区间可以逐情景比较；区间以中位数为零点显示相对偏差，并在同一行报告绝对中位数，以免窄区间被跨情景 Loss 差异压扁。
- **数据源：** `Q3/04_结果/Q3_T3_稳健性与配置切换/q3_bootstrap_summary.csv`。
- **图型与映射：** 单一森林图；y 为预算—上下文情景，点位于各情景的中位数（相对偏差 0），水平区间为 `predicted_loss_p2_5`–`predicted_loss_p97_5` 相对中位数的百分比偏差，右侧数值列保留绝对 `predicted_loss_median`。预算以颜色、上下文以点形冗余编码。
- **统计口径：** 每情景 1,000 个既有轨迹簇 Bootstrap 复本；独立 B1 轨迹数为 8。点为中位数，线段为 Bootstrap 2.5–97.5 百分位范围。
- **解释边界：** 这是 8 条 B1 轨迹、固定 Q₀、固定 M0 函数形式和已观测支持域内的参数敏感性，不是模型形式误差或域外不确定性。N/D 配置区间每情景退化为单一网格点；本图不将配置画成分布。
- **支持域与单位：** 预算为 FLOPs；上下文长度为 tokens；Loss 为 M0 预测验证 Loss。数据覆盖 3 个预算 × 5 个上下文，共 15 情景。
- **导出：** SVG、301 dpi 彩色 PNG、同尺寸灰度预览；按双栏 7.2 in 宽布局。横轴为相对百分比偏差，绝对中位数列为 M0 验证 Loss。
