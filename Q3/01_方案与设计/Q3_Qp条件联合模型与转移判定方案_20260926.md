# Q3 Q/p 条件联合建模与转移判定方案

版本：v1；日期：2026-09-26。范围：依照可见题面完成 Q2 可用模型的补充估计、预算情景计算与转移检验；不把分来源结果改写成真实联合训练实验。

## 1. 本方案要回答的问题

Q2 明确要求在经典 `N,D` 标度律上考察数据质量 `Q` 与配比 `p`，完成估计、检验和验证。Q3 明确要求预算约束下的资源配置及结构转移分析；题面允许将 `p` 固定为前问所得配置，但必须给出依据。本方案因此尝试两条可复核路径：

1. **Q 响应估计：**分别对 B6 半合成、B8 calibrated、B8 extrapolated 数据拟合同一完整 `M_Q_NDQ` 曲面；`κ` 允许取正、零或负。每个来源独立报告，不把 B7 的重复行当成独立样本，也不把不同来源的整组参数拼成一条曲面。
2. **Q3 B1 锚定敏感性：**冻结 B1 M0 的五个参数，只在每个 Q 来源内重新估计一个有符号 `κ`，考察完整 M0 数据项上的相对 Q 响应。该步骤须同时报告拟合优度、留一 Q 水平预测和支持域交集；这是跨源迁移压力测试，不是 B1 实测 Q 效应。计算时暂用 `Q_score` 与 Q1 `q_huber` 的数值同尺度假设；因该映射尚未验证，所有 Q3 联合结果标为条件情景。
3. **预算与转移：**B6 和 B8 calibrated 各自用其 B1 锚定 `κ`，在各自数据支持域与 B1 1,176 个 `(N,D)` 点的交集中求解题面 15 个预算×上下文情景；B8 extrapolated 仅作独立曲面外推诊断，不跨越其 N 支持域用于 B1 优化。若来源估计的方向冲突，分别呈现两套最优解与转移结论，不选边合并。
4. **p 效应和固定配比：**保留 Q1.3 已估的 A 侧 `p→Loss` 系数与跨尺度实测检验；既有迁移 R² 为 1M `0.6189`、60M `-7.9336`、1B `-810.1196`。因此 Q3 按题面允许的固定配比分支，固定 B1 共同数据政策 `p=p0`，其数值 17 维向量未知、效应并入 B1 M0 基线；不把 A 侧 p 系数硬接入目标函数。此分支回答固定配比下的 Q/N/D 预算转移，不声称 B 侧 p 增量已识别。

## 2. 条件模型与变量口径

来源 `s` 的 Q 响应估计模型写作：

\[
L_s(N,D,Q_s)=E_s+A_s N^{-\alpha_s}+B_s D^{-\beta_s}\left(\frac{Q_s}{Q_{ref,s}}\right)^{-\kappa_s},
\]

六参数分来源拟合使用未加权最小平方损失；约束 `0≤E_s<min(Loss)`、`A_s>0`、`B_s>0`、`10^{-4}≤alpha_s,beta_s≤2`、`-4≤kappa_s≤4`。正系数以对数参数化，多初值固定为 E 的 3 个分位起点、幂指数 3 个起点、κ 的 6 个起点（共 54 组）；保留成功解中残差平方和最小者，记录成功数、边界命中和近优解参数跨度。`Q_ref,s` 固定为该来源训练子集的 Q 中位数以改善数值条件。B1 锚定压力测试固定 B1 M0 的 `E,A,alpha,B,beta`，只在同一 `[-4,4]` 范围拟合有符号 `kappa_s`；拟合目标、初值和失配诊断与全曲面分支一致。该来源拟合不自动等于 B1 模型；锚定估计按 `Q_score=Q1 q_huber` 数值身份映射生成条件曲面，只有在该映射及锚定残差经验证后才可称为 B1 迁移模型。当前它们均是显式假设的敏感性分支。所有 `N,D` 拟合输入沿用十亿单位，成本计算先换为绝对计数。

- **有利 Q 来源：**B6 重新拟合六参数模型，B7 与 B6 的 360/360 行完全重复，只作复现核对，不作为第二个独立样本。
- **反向 Q 来源：**B8 `data_type=calibrated` 与 `data_type=extrapolated` 分开拟合完整六参数模型；有符号 `κ_s` 由非线性损失模型拟合估计，不能从固定 `(N,D)` 的 `log Loss` 斜率直接代替。
- **配比 p：**Q3 条件优化固定 `p0` 为 B1 共用训练政策，不虚构其 17 维数值向量。B1 的 `p` 效应无法从单一政策组内拆出，故 M0 系数解释为给定该政策的条件基线。另行呈现 Q1.3 的 A 来源 `p→Loss` 估计与跨尺度传递检验；迁移未通过，故不把 A 系数乘进 B1 目标函数。

## 3. 题面成本约束与求解

沿用已审计的题面成本：

\[
C_{total}=6ND+D[g(Q)-g(Q_0)]_+ +2\times10^{-4}NDL_{ctx}\le C,
\]

使用题面三个预算、C7 五个上下文长度、三种 `g(Q)`。`(N,D)` 候选来自冻结 B1 的 1,176 个实际观测点，但每个 Q 来源还须与其观测支持域取交集：B6 为 `N=0.07–11.97B,D=10–600B`；B8 calibrated 为 `N=0.07–12B,D=5–2000B`；B8 extrapolated 的 `N=20–700B` 与 B1 网格无交集，不进入 B1 优化。每个来源、预算和上下文组合均在计算前重新做可行性预扫；无可行点时报告 infeasible，不沿用全网格 M0 的可行计数。主求解对支持交集内有限 `(N,D)` 网格逐点穷举；每个可行点的内层 Q 则按预算连续求解可负担上界（用单调成本函数的二分法）。单调幂响应下按估计 `kappa` 的符号取 `Qmax`（有利方向）或 `Q0`（反向/零方向）。记录成本分项、预算利用率、候选数、预算残差及边界状态。

三类 `g(Q)` 分别独立优化。B6 与 B8 的 Q 系数单独运行，条件最优结果不合并；若 B6 与 B8 的转移判定或最优解冲突，则结论为 Q 响应尚无可迁移的唯一方向，不能报告唯一经验联合最优。

## 4. 转移与验证判据

- 每个来源分支先报告完整 15 情景候选数与可行状态。因最低预算、最长上下文情景无可行候选，结构差异指标只对剩余可比较的 20 条相邻边计算（原 22 条边中剔除与该无解节点相连的两条）；另将这两条边作为“进入/退出可行域”单独报告，不计算 N/D 或成本份额差。
- B6、B8 calibrated 的 B1 锚定分支分别报告；B8 extrapolated 完整曲面只作模型形式与方向诊断。将来源分支间的解差异作为模型/迁移敏感性，不混入 Bootstrap 区间。
- 对 B6 与 B8 calibrated 的匹配 `(N,D)` 支持单元进行 1,000 次 cluster bootstrap，估计 B1 锚定 `κ` 的网格稳定性区间；完整六参数曲面的不确定性另以确定多初值跨度与留一 Q 水平误差呈现。B1 既有 8 轨迹 bootstrap 参数复本作为 M0 参数不确定性。不得把 Q 校准网格重抽样称为真实训练抽样，也不得与 B1 轨迹复本混成同一数据层级。
- 用 Q1.3 现有锁定系数评估 A→B 跨尺度 p 转移。已有绝对 Loss 结果：A 同尺度 1M `R²=0.6189`，60M `R²=-7.9336`，1B `R²=-810.1196`；追加中心化诊断可评估配比排序/相对变化是否比绝对水平更稳定，但不得改称无偏验证。
- 本分支的 Q 响应训练源为半合成/校准数据，不是 B1 真实 Q 变化。若 B6/B8 符号不一致，Q3 输出是条件情景包络；这不满足真实 `Q→Loss` 迁移通过标准。

## 5. 预先声明的停止条件

满足以下全部条件才允许称为题目所需的完整、经验支持的 Q/p 联合最优：

1. A→B p 传递有未参与拟合的可比来源验证，且目标域/损失聚合口径通过核验；
2. Q1 `q_huber` 与 Q2 Q-score 的量纲和方向建立可验证映射，B6/B8 不再呈现未解释的方向冲突；
3. 在可比的 N/D 范围内，Q 与 p 具有可区分的变化或已明确采用固定 p 的题面允许分支；
4. 预算优化与转移结论在经来源/轨迹聚类的不确定性分析下稳定。

任一项失败时，本方案仍完成来源内 Q 参数估计、A 侧 p 迁移诊断、留出检验、B1 锚定迁移压力测试、可行域内预算求解、20 条可比较相邻边的结构转移对照及 2 条可行域边界转移报告；B 侧 p 效应仍未估计。失败分支照实保留，但不把来源条件结论包装成已验证的统一经验 `Loss=f(N,D,p,Q)`。这一区分是完成题目估计/优化要求与证据是否支持跨源外推之间的区别，不是跳过估计步骤。
