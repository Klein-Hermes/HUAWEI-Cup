# Q3-G2 结构性转移判定计划

日期：2026-09-26  
范围：完成问题三“预算跨量级时是否出现结构性转移”的定义、识别、稳健性计算与结果收口；不据此宣称完整 Q/p 联合模型已识别。

## 1. 题目要求与当前缺口

题目要求分析不同算力预算下的最优策略是否发生质的变化，并给出数学定义和识别方法。项目题目分析报告将结构性转移界定为：活动约束集合、资源份额排序或边际收益排序的改变超过 Bootstrap 或数值误差范围。

既有固定 \(Q=Q_0\) 分析确认了相邻预算档的 N/D 网格最优点改变，但有限网格点改变本身不等于结构性转移；旧报告因此只称其为“离散配置切换”。本计划把活动约束判据改写为有限候选优化可直接计算的“有限支持域内预算限制状态”，并用已冻结的 B1 支持域及 Q2 轨迹 Bootstrap 判定状态是否跨预算档改变。结论名称限定为“有限网格预算限制状态转换”，不声称连续或全局策略相变。

## 2. 有限网格活动状态的数学定义

令 \(G=\{(n_j,d_j):j=1,\ldots,1176\}\) 为 B1 实测候选集合，其中 \(n_j=N_{\mathrm{params},j}/10^9\)、\(d_j=D_{\mathrm{tokens},j}/10^9\)，即 B1 表中的十亿参数和十亿 Token 数值；\(L\) 为 C7 上下文长度，\(\theta_b=(E_b,A_b,\alpha_b,B_b,\beta_b)\) 为第 \(b\) 个 Q2 轨迹 Bootstrap 复本。固定 \(Q=Q_0\) 与 B1 共同训练配比政策时：

\[
\widehat L_{j,b}=E_b+A_bn_j^{-\alpha_b}+B_bd_j^{-\beta_b},\qquad
C_j(L)=6(10^9n_j)(10^9d_j)+2\times10^{-4}(10^9n_j)(10^9d_j)L.
\]

先在整个有限支持域上求无预算限制的最优点

\[
j^*_{b}=\arg\min_{j\in G}\widehat L_{j,b}.
\]

定义预算限制状态

\[
a_b(C,L)=\mathbf 1\{C_{j^*_b}(L)>C\}.
\]

当 \(a_b=1\) 时，预算排除了支持域内无预算限制的最优候选，故预算约束限制了有限支持域最优解；当 \(a_b=0\) 时，该候选可行，解由当前实测支持域限制。判定要求无预算限制最优点唯一。由于损失对 \(N,D\) 严格递减的充分条件是 \(A_b,\alpha_b,B_b,\beta_b>0\)，且 1,000 个 Q2 Bootstrap 复本均满足该条件，当前模型的唯一 \(j^*_b\) 是 B1 支持域中唯一的联合最大 \(N,D\) 点；状态切换阈值等于该上下文下所有支持点成本的最大值 \(C_{sat}(L)=\max_j C_j(L)\)。

对相邻预算 \(C_i<C_{i+1}\)，若配对 Bootstrap 中 \(a_b(C_i,L)\ne a_b(C_{i+1},L)\) 的比例不低于 0.95，判为一次有限网格预算限制状态转换。预算后最优点是否到达共同支持域的 \(N_{max},D_{max}\) 仅作为一致性校验；它由状态定义和单调损失推得，不是另一份独立证据。该定义是离散可行域下的活动约束类比，不使用连续优化器 KKT 条件，也不把它解释为支持域外的真实规模上限。

## 3. 预先判定规则

1. 使用题面三档预算 \(10^{19},10^{22},10^{24}\) FLOPs 与 C7 五个上下文长度；逐上下文比较低→中、中→高两段。
2. Bootstrap 单位沿用已冻结 Q2 B1 八条轨迹的 1,000 个拟合复本。每个复本在两端预算使用同一参数抽样，维持配对。
3. 判定阈值沿用项目既定稳定性门槛 95%；候选成本由整数计数重算，预算状态不设“接近饱和”人为阈值。
4. 分开报告：(a) 预算限制状态是否改变，(b) N/D 离散最优点是否改变，(c) 训练与注意力成本份额是否改变。只有 (a) 改变且通过 95% 配对门槛，才计作本计划定义的有限网格预算限制状态转换；(b) 单独发生只称为配置切换。预算后支持边界命中只作一致性校验。
5. 另将 B6 与 B8 calibrated 的 Q 响应条件分支作为敏感性核对。两来源的 \(\kappa\) 不合并；它们不能替代 B1 实测 Q 效应，也不用于抬高主判定的证据等级。

## 5. 结论范围

通过判定后，结论只覆盖 \(Q=Q_0\)、B1 共同配比政策、冻结 M0 和 1,176 点实测支持域。若状态在中→高预算跨越 \(C_{sat}\)，可据此明确回答“在当前支持域内是否出现预算限制机制向支持域限制机制的结构性转移”。不将这一结论外推到更大 \(N,D\)、未知 B 侧配比向量或未经验证的 \(Q\to q_{huber}\) 映射。Q/p 来源条件结果作为单独敏感性结论呈现。
