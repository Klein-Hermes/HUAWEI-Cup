# Q3-T3 收尾标准化执行计划

## 任务判断

这项收尾合理，且不需要增加实验。现有证据已包含 15 个固定 Q 情景的 1,000 次轨迹级 Bootstrap 摘要，以及 22 组相邻预算/上下文的配对配置变化审计。现阶段的缺口是交付接口：截图要求的 `q3_bootstrap_summary.csv`、`q3_configuration_switch.csv`、`q3_cost_structure_switch.csv` 尚未作为同一 T3 包提供；当前权威配对表把 N/D 最优配置改变率和成本份额改变率并列在一起，容易把两种切换混读。

因此本任务只重用现有权威结果，做字段与文件命名标准化、分开表达两类切换、补齐对应图件和来源哈希。**不重跑 Bootstrap、不增加复本、不重拟合、不改模型合同、不触碰 T2，也不冻结 Q3。**原始计算结果继续保留为来源真值，新增 CSV 是注明来源的标准化视图。

## 冻结前标准化合同

1. **情景内 Bootstrap 稳定性**：以 `M0_ND_cluster_bootstrap_frontier.csv` 为来源，15 行对应 3 档预算 × 5 种上下文；保留 1,000 个复本、基线/众数重选率、唯一选中网格点数、N/D 与预测 Loss 的分位数区间。
2. **跨情景 N/D 配置切换**：以 `M0_discrete_transition_pairs.csv` 为来源，22 行按同一 Bootstrap 复本配对比较相邻预算或相邻上下文；唯一主指标为 `configuration_change_frequency`，稳健切换门槛为频率 ≥95%。
3. **跨情景成本结构切换**：仍以同一权威配对表为来源，但输出独立的 22 行视图；唯一主指标为成本份额总变差非零频率 `cost_share_change_frequency`，稳健切换门槛为频率 ≥95%。保留成本份额 TV 统计量作为幅度描述，不把它与 N/D 配置切换合并成一个 `switch`。
4. 两种跨情景切换均基于 8 条训练轨迹、1,000 个成对 Bootstrap 复本和固定 Q0/M0/B1 支持域；只描述既有支持网格内的条件稳定性，不解释为外部验证、因果效应或完整 Q/p 联合优化。

## 执行顺序

| 阶段 | 操作 | 验收证据 |
|---|---|---|
| 1. 来源锁定 | 读取两份权威结果及各自 manifest；比对来源文件、上游输入和脚本哈希。 | 哈希匹配；Bootstrap 复本数 1000；15 个情景、22 个配对及 22,000 条配对明细完整。 |
| 2. 轻量 P1 | 用真实 CSV 执行标准化脚本的只读校验模式，在内存中构建三张标准表，不写正式产物。 | 行数、唯一键、区间字段、95% 门槛、两种指标隔离及关键计数均通过；独立 P1 回执 PASS 后再正式出图。 |
| 3. 标准化导出 | 新建独立 T3 输出目录，写三个约定文件名的 CSV、报告、图表契约和 SHA-256 复现清单。 | 来源真值不变；三张表字段语义可追溯；配置切换表不含成本结构主指标，成本结构表不含 N/D 切换主指标。 |
| 4. 对应图件 | 分别为 Bootstrap 稳定性、N/D 配置切换、成本结构切换生成独立图件；输出 SVG、PDF、300 DPI PNG 和灰度版。 | 每图只呈现一个主要口径；显示样本数/复本数和稳健门槛；图中文字与表格、报告数值一致。 |
| 5. 收尾复核 | 运行图表形式门禁、渲染审图和独立只读终审；更新 T3 执行记录与 Q3 索引。 | 所有 manifest 哈希一致；脚本从项目根目录可复现；独立 T3 范围复核 PASS。Q3 总体 P2/冻结门禁仍另行保留。 |
