## 2. 解析边际效应、弹性与 Q—N 替代条件

令 S=A N^{-alpha}、T=B D^{-beta} exp(-beta h(Q,p))，L=E+S+T，且 A,B,alpha,beta>0。若 h 不直接依赖 N,D，则：

- dL/dN = -alpha S/N；epsilon_N = -alpha S/L。
- dL/dD = -beta T/D；epsilon_D = -beta T/L。
- dL/dQ = -beta T h_Q；epsilon_Q = -beta T Q h_Q/L。
- 在固定 D,p 和目标 L*=L 下，dN/dQ|L = -L_Q/L_N = -beta T h_Q N/(alpha S)。当 h_Q>0 时该斜率为负：更高 Q 可容许更小 N，但斜率大小需要可识别的 Q 系数。
- 若采用 h(Q,p)=gamma log(Q/Q_ref)+g_p(p)，则 D_eff 中的质量倍率为 (Q/Q_ref)^gamma；固定有效数据量时 D_new/D_old=(Q_old/Q_new)^gamma。若同时约束目标 Loss，应用 N(Q)=[A/(L*-E-B D^{-beta} exp(-beta h))]^(1/alpha)，且括号分母必须为正。

这些是带条件的解析结果，不是已估计的数值替代率；Q1 的 q_huber 操作接口冻结，也不能替代 B 侧独立 Q 变化。该替代率是等 Loss 关系，不是等算力/等成本关系。

## 3. 配比的可行替代与互补定义

p 位于 17 维单纯形，故不能把 17 个分量当独立普通变量。域 j 向域 i 转移 delta 时，p(delta)=p+delta(e_i-e_j)，可行范围为 -p_i <= delta <= p_j（若 delta 定义为从 j 转给 i；相反约定需相应换号）。其局部损失变化为 -beta T [h_{p_i}-h_{p_j}]。它回答一个 10 个百分点配比替代对 Loss 的局部影响。

领域互补性需要先指定两个保持单纯形约束的转移方向 u、v，并定义混合有限差分 Delta_u Delta_v L。局部二阶项为 D_uD_vL=T[beta^2(D_uh)(D_vh)-beta D_uD_vh]。按 Loss 约定，若该二阶项小于 0，第二种转移增强第一种转移的降 Loss 收益，称为该基点与方向下互补；大于 0 表示边际收益减弱，称为替代；接近 0 则无可辨互补/替代。该结论依赖参照配比和方向，不能把无约束 Hessian 元素当成普遍的域关系。

A4/A5 当前线性 p-only 主模型可估计来源内方向替代；由于其对 p 为线性，在此主模型设定下任意两个单纯形内转移方向的二阶交叉导数都为 0。这是模型施加的无曲率限制，不是数据证明领域间没有互补。另对 512 个精确训练配方组实施 500 次配方组 Bootstrap 的二次敏感性分析：全样本筛出的 6,551 个可行转移对中，未校正逐点区间有 273 对全负、445 对全正、5,833 对跨零；对候选对作条件 max-|t| 家族校正后，0 对全负、39 对全正、6,512 对跨零。正向区间表示该基点和两个单独有利转移组合下呈边际收益递减，不等于普遍的域互补/替代结论。候选方向由同一全样本筛选，家族校正条件于该候选集（max-|t| 临界值 6.5403），未调整选择步骤；结果属 A 侧探索性敏感性，不能外推到 B 侧。A 侧外推到 60M/1B 失败。当前 B 侧没有 p 行级连接，所以不能把 A 侧替代系数或探索性曲率迁移为 B 侧标度律参数。逐配对区间、汇总和完整条件限制见 `a_side_complementarity/` 子目录。

## 4. A 侧配比证据与跨尺度边界

A4/A5 的 simplex_ridge 在 1M 同尺度留出集 13 目标宏平均 R2=0.6189；60M=-7.9336；1B=-810.1196。因此只能写来源内、同尺度关系，不支持跨尺度通用 p 系数。

17 域 10pp 替代 Bootstrap 统计沿用 Q1.3 已冻结文件：136 个域对中 106 个有训练支持；对应 1378 个目标×域对区间，其中全正 214、全负 535、跨零 629。这些是模型条件下的逐点区间，没有多重比较调整，不作为因果或 B 侧推断。A 侧 p+Q 模型中 Q_covered(p) 是配比的确定性函数。direct-only q_huber 的嵌套流程标准化 RMSE=0.763353642，二次 p-only=0.595169982，差=+0.168183660；配对表的非嵌套 macro_normalized_rmse 差=+0.168174185，指标定义不同、数值略异，两者都显示加入 Q_covered(p) 未改善结果。路线复审中误把 q_equal 的 0.7533 标成 q_huber，现以 q_huber 的机器结果为准。

## 5. B6/B7 半合成 Q 响应与 B8 冲突审计

B6 有 360 行、8 个 Q 水平；固定 N,D 的 45 组中 Loss-Q 线性斜率为负 45 组、正 0 组。B7 有 450 行、10 个 Q 水平；固定 N,D 的 45 组斜率为负 45 组、正 0 组。B7 与 B6 的重合 360/360 行完全复用且 Loss 改动 0 行，因此 B6/B7 不是独立复制实验。

在 B6 上，带 Q 的 h=gamma log(Q) 形式留一 Q 水平 RMSE=0.0898401，M0 N/D RMSE=0.145135；拟合 gamma=1.21645，合成网格内 Q 弹性中位数=-0.054048，多初值最优解相对参数跨度最大值=0.000579。B7 对应 RMSE 为 0.084316 与 0.12954，gamma=1.17977，网格内 Q 弹性中位数=-0.0520551，多初值最大相对跨度=0.000361。这些分数只检验半合成网格对预设形式的响应/插值能力，不是对真实 B1–B5 的验证，也不能证明 Q1 的 q_huber 与 CSV 的 Q_score 同尺度。
等 Loss 数值示例固定共同网格中心 N=1B、D=150B、Q=0.6：B6 拟合在 Q 增加 0.1 后对应 N=0.878085B（变化 -0.121915B）；B7 为 N=0.881795B（变化 -0.118205B）。这只是半合成拟合曲面上固定 D 的等 Loss 代数示例，不是实际模型缩放建议或真实资源替代率；完整点值保存在 `b6_b7_q_n_equal_loss_demo.csv`。

B8 calibrated：n=984，固定 N,D 组=90，Q 斜率负/零/正=0/0/90，中位配对斜率=2.02786。
B8 extrapolated：n=720，固定 N,D 组=60，Q 斜率负/零/正=0/0/60，中位配对斜率=1.81051。

B8 与 B6/B7 的方向相反，且在固定 N,D 后依然相反；所以这不是只靠总体 Q 分组造成的表象。B8 的 calibrated/extrapolated 层也分别呈正向。未找到可验证生成规则前，不合并三份数据拟合唯一 Q 弹性；B6/B7 只作为数据说明允许的半合成补充，B8 保留为数据/生成一致性问题。

## 6. B9/B10 大尺度外推情景

对 B10 的 128 行估算 Loss，直接代入冻结 B1 M0 参数，不重拟合。B1 支持上限为 N=11.9658B、D=299.893B；B10 有 128 行 N 超出 B1 范围、102 行 D 超出 B1 范围。B10 M0 预测 Loss 范围 1.78384–4.0863，中位数 1.90642。逐模型点值和由 8 个独立 B1 轨迹 Bootstrap 参数传播得到的范围在 `b9_b10_m0_extrapolation.csv`。

## 8. M1/M2 当前数据不可识别性的代数说明

B1 只有一个共同配方政策组。若 p 为固定 `p_0`，M1 中 `B exp[-beta g_p(p_0)]` 可并入单一数据项系数，模型与 M0 完全同形；不能从中估计 p 增量或域替代关系。若改用公共累计组成 `p(D)`，则必须从 token 流真实重建，并依赖预先规定的低维 `g_p` 及可区分于 D 的支持；当前没有 checkpoint 级源 token 计数。对 M2，若 `Q=Q_covered(p)`，一般函数层面的 p/Q 分解不唯一；受限参数化可以增加预测基函数设计秩（本例 direct-only q_huber 为 17→18），但这不证明独立 Q 变化，且嵌套 OOF p+Qcovered 标准化 RMSE=0.763354，高于二次 p-only 的 0.595170。详细证明、条件和重开门禁见 [`q2_m1_m2_identifiability_proof.md`](q2_m1_m2_identifiability_proof.md)。
