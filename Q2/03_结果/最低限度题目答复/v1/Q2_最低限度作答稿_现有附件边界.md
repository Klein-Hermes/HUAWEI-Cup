状态：**题面答项已按现有数据完成条件性作答；B 侧独立联合效应尚未由数据识别。** 题面明确要求在经典标度律基础上纳入 \(Q\) 与 \(\boldsymbol p\)，估计边际效应和无量纲弹性，并讨论质量与参数的替代条件；题面没有逐字规定必须在同一 B 侧运行中观测到彼此独立变化的 \(p,Q\)，也没有明文要求因果识别。共同运行记录和独立变化是本研究若要把两项系数解释为 B 侧独立联合效应时所需的统计识别条件。本稿据此区分题面答项与经验识别强度；跨数据源组合只作条件校准。

## 1. 广义标度律

以 B1 估计的经典标度律为基线，令

\[
L=E+A N^{-\alpha}+B D_{\rm eff}^{-\beta},\qquad
D_{\rm eff}=D\exp\{h(Q,\boldsymbol p)\},
\]

并令参考状态满足 \(h(Q_{\rm ref},\boldsymbol p_{\rm ref})=0\)。为得到当前资料下参数最少、可解释的扩展，采用可加主效应形式

\[
h(Q,\boldsymbol p)=g_p(\boldsymbol p)+\gamma_Q\log(Q/Q_{\rm ref}).
\]

这是模型限制，不是数据证明不存在 \(p\times Q\) 交互。由于现有配比记录和质量记录没有共同的 B 侧训练运行键，\(g_p\) 与 \(\gamma_Q\) 只能从不同来源分块校准；由此得到的合并数值必须解释为条件情景。

为给出一个具体的 \(p\) 边际量：在 A4/A5 平均闭合配方处，把 10 个百分点从 `train_the_pile_arxiv` 转到 `train_the_pile_freelaw`，simplex-ridge 对 Arxiv 验证 Loss 的预测增加 0.39629（配方组 Bootstrap 95% CI [0.33531, 0.45569]）；这项转移只在 28.1% 的训练配方中有供体份额支持。以平均闭合配方预测 Loss 5.04406 为参照，有限 10pp 变化约为 +7.86%。对组成数据，方向弹性定义在 log-ratio 坐标上：

\[
\varepsilon_{i/j}
=\frac{1}{L}\frac{\partial L}{\partial\log(p_i/p_j)}
=\frac{\partial L/\partial\delta}{L(1/p_i+1/p_j)},
\]

其中 \(\delta\) 表示从域 \(j\) 向域 \(i\) 的转移。该参考配方的局部方向弹性为 0.04097；将转移效应 Bootstrap 区间代入而固定参照配方得到的条件区间约为 [0.03467, 0.04711]。这是 A 侧、Arxiv 目标和该转移方向的条件结果，不能推广成所有域共享的配比弹性或 B 侧标度律系数。

## 3. 边际效应与无量纲弹性

令 \(S=A N^{-\alpha}\)、\(T=B D^{-\beta}\exp[-\beta h(Q,\boldsymbol p)]\)，则

\[
\frac{\partial L}{\partial N}=-\frac{\alpha S}{N},\quad
\varepsilon_N=-\frac{\alpha S}{L};\qquad
\frac{\partial L}{\partial D}=-\frac{\beta T}{D},\quad
\varepsilon_D=-\frac{\beta T}{L}.
\]

在 \(h=g_p(\boldsymbol p)+\gamma_Q\log(Q/Q_{\rm ref})\) 下，

\[
\frac{\partial L}{\partial Q}=-\frac{\beta\gamma_Q T}{Q},\qquad
\varepsilon_Q=-\frac{\beta\gamma_Q T}{L}.
\]

因此，B6/B7 的负质量弹性只表示相应半合成曲面上的条件结果。配比是组成向量；从域 \(j\) 向域 \(i\) 转移份额 \(\delta\) 的边际效应为

\[
\frac{\mathrm dL}{\mathrm d\delta_{i\leftarrow j}}
=-\beta T\left(\frac{\partial g_p}{\partial p_i}-\frac{\partial g_p}{\partial p_j}\right).
\]

## 4. 质量—规模等 Loss 替代

固定 \(D,\boldsymbol p\) 和目标 Loss 时，

\[
\left.\frac{\mathrm dN}{\mathrm dQ}\right|_L
=-\frac{L_Q}{L_N}
=-\frac{\beta\gamma_Q T N}{\alpha S Q}.
\]

B6/B7 在各自半合成拟合曲面上，以 \(N=1\)B、\(D=150\)B、\(Q=0.6\) 为例，令 \(Q\) 增至 0.7 后等 Loss 的 \(N\) 分别为 0.87808B、0.88179B。该数值是公式代入的情景示例，不是现实模型缩放建议；它也不包含训练成本和计算量约束。

## 5. 最低限度结论与验证声明

现有附件足以给出 M0 基线、A 侧同尺度配比效应、B6/B7 半合成质量响应、解析弹性和等 Loss 替代关系。为在一个表达式中纳入题目要求的变量，可报告上述可加主效应广义标度律，并明确其分块校准假设。

现有资料不足以把该式表述为“真实 B 侧独立联合效应已估计并验证”：B1–B5 中经核验并与 Loss 联接的累计配比 \(p(D)\) 行数为 0；A 侧配比模型未通过跨尺度预测；Q 侧质量补充为半合成且 B8 方向相反。因此，本稿把 B 侧独立联合参数状态记为 **未由共同真实观测识别**，不把跨来源代入值写成实证联合系数。此处“未识别”说明证据强度，不是把题面没有明文提出的因果识别条件追加为竞赛硬性要求。

若后续取得同一训练设计中的配比变化、独立质量变化、checkpoint 级累计域 Token 计数和可比 Loss，再按 M0→M1→M2 顺序估计并作按运行/配方留出验证。当前版本不新增训练试验，也不重拟合已冻结的 M0、A 侧模型或半合成 Q 模型。
