# Q2 补充绘图任务单

## 任务目标

为当前 Q2 论文草稿补充三张有明确论证作用的图，并视工作量补充一张残差诊断图。现有 Q2 基线已有原始数据、拟合过程、结果图各 3 张及总体流程图；本任务只生成补充图，不重画、不覆盖现有图，也不修改源数据、模型结果或报告。

## 输出与复现要求

- 图片统一保存到：`Q2/归档_20260925/Q2补充图表/`。
- 绘图脚本保存到：`Q2/归档_20260925/plot_q2_supplementary_figures.py`，从项目根目录运行可复现所有新图。
- 每张逻辑图导出 SVG、至少 300 DPI 的 PNG 和灰度预览；文件名按下方指定。SVG/PNG/灰度预览是同一逻辑图的不同格式。
- 色盲友好配色；面板标题、坐标轴、单位和图例完整，最终尺寸下文字清楚且无裁切。
- 在 `Q2/归档_20260925/Q2补充图表/图表契约.md` 中记录每张图的结论、图型、数据源、统计口径和限制。
- 原始 CSV、JSON、既有结果报告和 `Q2/04_图表/q2_scaling_baseline/` 下原图均只读。
- 不补造数据，不拟合新的 Q2 模型，不把当前未识别的 p/Q 系数画成估计结果。

## 必画图 1：M0 的 N、D 弹性随训练进度变化

**文件名：** `result_q2_m0_elasticity_profile.svg`、`result_q2_m0_elasticity_profile.png`、`result_q2_m0_elasticity_profile_grayscale.png`

**核心结论：** 在冻结的经典 M0 模型内，N 和 D 的模型蕴含弹性随模型规模与训练进度变化；这些是 N、D 的效应，不是 p/Q 效应。

**图型与布局：** 两行 × 四列小面板。列按模型规模从小到大；上行为 `elasticity_N`，下行为 `elasticity_D`。横轴为训练量 D（十亿 Token），使用对数轴；同一行的面板共用纵轴范围。每个面板按 D 排序连线，估计值画实线，Bootstrap 区间画半透明带。

**数据源：** `Q2/03_结果/经典ScalingLaw基线/v1/q2_m0_marginal_effects_by_checkpoint.csv`。

**字段：** `B12_model_size`, `N_params_B`, `D_tokens_B`, `elasticity_N`, `elasticity_N_lower_95`, `elasticity_N_upper_95`, `elasticity_D`, `elasticity_D_lower_95`, `elasticity_D_upper_95`。

**处理口径：** 使用全部 1,176 行，按 `B12_model_size` 分组、组内按 `D_tokens_B` 排序；共 8 个模型规模，每组 147 个检查点。区间直接使用 CSV 中的 lower/upper 列，不重新抽样或重拟合。

**图注必须说明：** 95% 区间来自 8 条完整 Pythia 轨迹的 cluster Bootstrap；独立轨迹数较少，区间仅作稳定性提示。弹性是冻结 M0 下的模型蕴含量，不是因果效应。

## 必画图 2：附件 A 配比模型的跨尺度表现

**文件名：** `result_q2_A_p_only_cross_scale.svg`、`result_q2_A_p_only_cross_scale.png`、`result_q2_A_p_only_cross_scale_grayscale.png`

**核心结论：** 附件 A 的 p-only 配比模型在同尺度与跨尺度评估间表现差异明显；该结果不能直接迁移为 B 侧 p 效应。

**图型与布局：** 两个并列面板，横轴按 `test_1m`、`test_60m`、`test_1b` 排列。每个尺度显示 13 个领域目标的散点，并用醒目的菱形标出 13 个目标等权宏平均，不绘制置信区间。

- 左面板：逐目标 RMSE，纵轴从 0 起。
- 右面板：逐目标 R²，标出 R²=0 参考线；使用对称对数纵轴，并明确标注 `symlog`，以保留极端负值同时显示零附近结果。

**数据源：** `Q1/03_结果/Q1.3/v1/holdout_metrics.csv`。汇总值与评估口径核对 `Q1/03_结果/Q1.3/v1/q1_3_run_report.md`。

**筛选口径：** `model=simplex_ridge`、`variant=closed`；保留 `split` 为 `test_1m`、`test_60m`、`test_1b` 的记录。按 13 个 `target` 分别画 `rmse` 和 `r2`，宏平均为 13 个目标指标的算术平均；不可将样本拼接后重新计算 R² 或 RMSE。

**使用字段：** `split`, `role`, `model`, `target`, `n`, `rmse`, `r2`, `variant`。

**核对用宏平均值：** `macro_r2` 约为 0.6189、−7.9336、−810.1196；`macro_rmse` 约为 0.4539、1.5590、3.1970。每个目标的 `n` 在 1M、60M、1B 分别为 256、256、64。

**图注必须说明：** 这是已有评估切分，不是新增盲测。点代表领域目标，不代表独立模型训练重复；没有置信区间时不要画误差棒。跨尺度表现仅用于说明迁移限制，不证明 B 侧配比效应。

## 必画图 3：B1–B5 配比数据与验证边界状态矩阵

**文件名：** `result_q2_p_gate_audit.svg`、`result_q2_p_gate_audit.png`、`result_q2_p_gate_audit_grayscale.png`

**核心结论：** 当前 B1–B5 没有已核验并连接到 Loss 的 17 维 p 向量，因此无法开始正式的 B 侧 p-only 拟合；不同来源还有各自的验证限制。

**图型与布局：** 文字标签状态矩阵；行是 B1–B5，列为：记录数/来源性质、是否有已核验数值 p、p 是否连接到 Loss、是否可作为独立真实验证、相对 B1 的 Loss 可比性。状态必须以文字呈现，颜色只作辅助，不使用连续数值色阶或 colorbar。

**数据源：**

- `Q2/03_结果/p配比可行性审计/v1/q2_p_audit_summary.json`
- `Q2/03_结果/p配比可行性审计/v1/q2_p_trajectory_mapping.csv`
- `Q2/03_结果/经典ScalingLaw基线/v1/validation_comparability.json`
- `Q2/03_结果/经典ScalingLaw基线/v1/loss_protocol_matrix.csv`
- 文字核对：`Q2/03_结果/p配比可行性审计/v1/q2_p_feasibility_audit.md`、`Q2/03_结果/经典ScalingLaw基线/v1/b4_b5_loss_comparability_audit.md`。

**必须呈现的状态：**

| 来源 | 记录数与性质 | 已核验 17 维 p | p-Loss 连接 | 验证角色 | Loss 可比性（相对 B1） |
|---|---|---|---|---|---|
| B1 | 1,176 个 Pythia 检查点；8 条轨迹 | 无 | 0 | 主参考来源 | 参考组；不是外部比较 |
| B2 | 1,029 条半合成轨迹 | 无 | 0 | 半合成压力测试 | 不作为真实外部验证 |
| B3 | 4,000 个 Pythia 插值点；8 条轨迹 | 无 | 0 | 同来源插值检查 | 不作为独立真实验证 |
| B4 | 57 个跨族记录；12 个模型族 | 无 | 0 | 行级来源/运行键缺失 | `NOT_COMPARABLE` |
| B5 | 44 个文献记录；9 个模型族 | 无 | 0 | 多来源汇编，缺行级运行键 | `NOT_COMPARABLE` |

**图注必须说明：** “0”表示当前审计材料中没有已核验且连接到 Loss 的 17 维配比，不表示真实训练中配比效应为零。B2 的半合成、B3 的插值、B4/B5 的 Loss 口径不可比是不同限制，不能合并成一个状态。

## 可选图 4：B1 残差随训练进度变化

**文件名：** `process_q2_B1_residual_by_D.svg`、`process_q2_B1_residual_by_D.png`、`process_q2_B1_residual_by_D_grayscale.png`

**核心结论：** 检查 B1 冻结 M0 的拟合残差是否随训练进度呈现阶段性偏移。

**图型与布局：** 八个模型规模做 2×4 小面板；横轴 `D_tokens_B`（对数轴），纵轴 `residual_pred_minus_obs`，加 y=0 参考线。每条轨迹内按 D 排序显示检查点，并以细线连接；不加平滑线、误差带或显著性标记。

**数据源：** `Q2/03_结果/经典ScalingLaw基线/v1/b1_fitted_predictions.csv`。

**字段：** `run_id`, `N_params_B`, `D_tokens_B`, `observed_val_loss`, `predicted_val_loss`, `residual_pred_minus_obs`。按 `N_params_B` 分为 8 个轨迹，每轨迹 147 点；`run_id` 只是记录定位符，不是独立样本单位。

**图注必须说明：** 这是 B1 拟合内残差，1,176 个检查点来自 8 条轨迹，不是 1,176 个独立实验。它不能作为外部验证结论。已有 `process_q2_residual_structure` 是残差对拟合值的诊断；若新图不能提供额外的随 D 变化信息，则跳过本图。
