# Q2 补充展示图

本目录收录三张 Q2 补充逻辑图的完整注释版和论文版。它们作为展示层补充，与 `q2_full_answer/` 中的既有图组并存，不覆盖已冻结的结果图，也不改变数据筛选、汇总值或模型结论。

## 复现

在项目根目录运行：

```powershell
"D:\Anaconda\python.exe" src/q2_supplementary_figures.py --output-dir Q2/04_图表/q2_supplementary
"D:\Anaconda\python.exe" src/q2_supplementary_figures.py --titleless --output-dir Q2/04_图表/q2_supplementary/论文版
```

`复现清单.json` 保存原始生成回执；当前包内的生成入口和命令也已登记在 [Q2 README](../../README.md) 与 [完成回执](../../05_审计交付/Q2补充绘图任务单_完成回执.md)。
