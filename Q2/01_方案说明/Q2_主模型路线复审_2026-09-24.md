## 一、回到题面确定 Q2 要回答什么

官方题面将问题二称为“跨维度数据融合与广义标度律”：在经典 `Loss=f(N,D)` 上纳入质量 `Q` 与领域配比向量 `p`，分析各因素边际效用和弹性、领域间替代/互补关系，并推导质量提升与扩大模型规模相互替代的条件。附件 A 与问题一属于同一数据集，Q2 使用问题一输出的 Q、p 信息；附件 B 提供主要 Loss 数据。题面同时要求对 A、B 两个独立实验作出可检验假设，再讨论如何连接。

因此，截图提出“重新判断 Q2 后半程是否能识别”的方向正确。更精确地说：Q2 需要估计 Loss 对 `N,D,p,Q` 的响应；`p,Q` 在 Q2 的边际效应分析中是输入/处理量。它们是否成为可控决策，要到 Q3 的资源优化中决定。不能把 Q2 改写成只列情景，却仍声称已估计 p、Q 的边际效应、弹性或替代率。

**模型数量合同：** M0、M1、M2 是同一广义标度律的嵌套限制，分别令 `h=0`、`h=h_p(p)`、`h=h_p(p)+h_Q(Q)`，用于递进识别和消融比较，不计为三个独立模型体系。只有预先限定的 `h_pQ(Q,p)` 交互项可作为唯一第二模型体系；当前数据不支持拟合该交互项。

## 五、完整 Q2 的可检验条件

后续若要声称完成题面要求的统一广义标度律，至少需要：

1. 明确 A、B 各自的 Loss 名称、单位、tokenizer、评测集/切分、预处理与测量对象；若量尺不同，先建立并检验桥接关系，不能直接合并数值。
2. 得到与每条训练运行或轨迹阶段匹配的 p；说明静态训练配方 `p_recipe` 与累计暴露 `p(D)` 的定义，不能把 checkpoints 当成相互独立配方。
3. 在同一来源内存在足够的 p 变化，并有支持估计 p 效应的实验设计；A 侧估计向 B 侧迁移需要额外可检验假设与验证，不能默认成立。
4. 使用已冻结的操作主 Q `Q1-q_huber-v1`，并在下游保留其人工小样本核查、机器翻译辅助和覆盖范围限制；若要估计独立 Q 效应，还须证明 Q 与 p 在当前设计中有独立变化。若 Q 是 `p` 的确定性函数，不能据回归系数宣称独立 Q 效应。
5. 将 M0/M1/M2 按同一广义模型族的嵌套限制，在共同可用样本、冻结切分和同一指标上比较；分别报告边际效应、弹性、替代条件的估计区间和适用范围。交互扩展最多作为第二模型体系，且须有支持数据。

若这些条件仍不满足，Q2 可提交的结论应限定为：经典 M0 基线、A 来源的配比实验结果、B 来源的描述性/趋势证据，以及数据不足导致统一的 p/Q 效应不可识别。情景计算可以作为明确标注参数假设的敏感性分析，不能替代缺失的数据识别。

## 本轮完整题意补充（2026-09-24）

补充收口结果见 [Q2 完整回答证据补充](../03_结果/完整回答补充/v1/q2_full_answer_evidence_supplement.md)。在不重拟合 M0、不污染原始数据的前提下，现已补齐：冻结 M0 与半合成 `h=gamma log(Q)` 形式的解析边际效应/弹性及等 Loss 条件；A 侧 17 域 10pp 替代区间计数；B6/B7 的固定 N,D 方向审计、多初值拟合和留一 Q 水平诊断；B8 的相反方向分层审计；以及 B9/B10 的超支持域 M0 情景预测。

B6/B7 的 Q 扩展多初值在 27/27 初值均收敛，报告的近最优解相对参数跨度最大值分别为 0.000579 与 0.000361；Q 模型在各自半合成网格的留一 Q 水平 RMSE 低于 M0。但 B7 完整复用了 B6 的 360/360 行，且 B8 在固定 N,D 条件下 150/150 组方向为正、与 B6/B7 相反。因此这些是对给定半合成表和模型形式的条件响应检查，不是独立真实 Q 效应证据，也不应合并估计单一质量弹性。

当前 M1/M2 的数据失败门禁已有代数解释：一个固定 B1 配方会使 p 项乘数并入 M0 的 D 系数；若 Q 是 p 的确定函数，`g_p(p)+g_Q(Q)` 存在不改变拟合值的等价分解。证明及重开条件见 [M1/M2 不可识别性证明](../03_结果/完整回答补充/v1/q2_m1_m2_identifiability_proof.md)。

在 B6/B7 共同网格中心的条件示例中（N=1B、D=150B、Q_score=0.6），半合成模型提高 Q_score 0.1 对应等 Loss 的 N 约下降 0.1219B（B6）和 0.1182B（B7）。这是模型内示例；B7 复用了 B6 数据，且 B8 方向冲突，因此不能称为真实规模替代率或推广到 Q1 的 `q_huber`。

领域关系方面，A 侧主线性单纯形模型下的互补曲率按模型结构固定为 0；这不能解释为数据验证了无互补。新增二次敏感性配方组 Bootstrap/max-|t| 分析后，6,551 个候选转移对中没有一个互补方向通过条件家族校正；39 对显示递减收益，其余区间跨零。候选转移是同一全样本筛选的，校正仅条件于候选集，因此这些仍是 A 侧探索性结果，不能升级为确认性结论或迁移成 B 侧经验效应。

B9/B10 仅用于量级情景：B10 的 128/128 个模型规模都超出 B1 的 N 支持范围，102/128 个 D 也超界；其 Loss 为整理估算，不构成外部验证。输入/输出与代码哈希、固定初值和复现命令列在该补充包的 `repro_manifest.json`。本轮只使用可见题面及 `数据说明(无隐藏字段版本）.pdf` 的可见文本层；没有把原始附件中的隐藏文本用于方法或结论。

这项补充使 Q2 的条件推导、来源内配比结果、半合成 Q 响应审计和大尺度情景都有可复核交付物；但当前真实 B1–B5 的 p-Loss 行级连接仍为 0，B 侧独立 Q 变化及跨源 Loss 量尺桥接仍未建立。故完整联合 `Loss=f(N,D,p,Q)` 的参数、真实 Q 弹性、数值 p/Q 替代率和联合验证仍未识别，Q2 不能标记为完整经验回答。
