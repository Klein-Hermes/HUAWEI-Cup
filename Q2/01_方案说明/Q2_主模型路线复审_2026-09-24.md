## 一、回到题面确定 Q2 要回答什么

官方题面将问题二称为“跨维度数据融合与广义标度律”：在经典 `Loss=f(N,D)` 上纳入质量 `Q` 与领域配比向量 `p`，分析各因素边际效用和弹性、领域间替代/互补关系，并推导质量提升与扩大模型规模相互替代的条件。附件 A 与问题一属于同一数据集，Q2 使用问题一输出的 Q、p 信息；附件 B 提供主要 Loss 数据。题面同时要求对 A、B 两个独立实验作出可检验假设，再讨论如何连接。

因此，截图提出“重新判断 Q2 后半程是否能识别”的方向正确。更精确地说：Q2 需要估计 Loss 对 `N,D,p,Q` 的响应；`p,Q` 在 Q2 的边际效应分析中是输入/处理量。它们是否成为可控决策，要到 Q3 的资源优化中决定。不能把 Q2 改写成只列情景，却仍声称已估计 p、Q 的边际效应、弹性或替代率。

**模型数量合同：** M0、M1、M2 是同一广义标度律的嵌套限制，分别令 `h=0`、`h=h_p(p)`、`h=h_p(p)+h_Q(Q)`，用于递进识别和消融比较，不计为三个独立模型体系。只有预先限定的 `h_pQ(Q,p)` 交互项可作为唯一第二模型体系；当前数据不支持拟合该交互项。

## 五、完整 Q2 的可检验条件

后续若要声称完成题面要求的统一广义标度律，至少需要：

1. 明确 A、B 各自的 Loss 名称、单位、tokenizer、评测集/切分、预处理与测量对象；若量尺不同，先建立并检验桥接关系，不能直接合并数值。
2. 得到与每条训练运行或轨迹阶段匹配的 p；说明静态训练配方 `p_recipe` 与累计暴露 `p(D)` 的定义，不能把 checkpoints 当成相互独立配方。
3. 在同一来源内存在足够的 p 变化，并有支持估计 p 效应的实验设计；A 侧估计向 B 侧迁移需要额外可检验假设与验证，不能默认成立。
4. 使用已冻结的操作主 Q `Q1-q_huber-v1`，并在下游保留其人工小样本核查、机器翻译辅助和覆盖范围限制；若要估计独立 Q 效应，还须证明 Q 与 p 在当前设计中有独立变化。若 Q 是 `p` 的确定性函数，不能据回归系数宣称独立 Q 效应。
5. 将 M0/M1/M2 按同一广义模型族的嵌套限制，在共同可用样本、冻结切分和同一指标上比较；分别报告边际效应、弹性、替代条件的估计区间和适用范围。交互扩展最多作为第二模型体系，且须有支持数据。

若这些条件仍不满足，Q2 可提交的结论应限定为：经典 M0 基线、A 来源的配比实验结果、B 来源的描述性/趋势证据，以及数据不足导致统一的 p/Q 效应不可识别。情景计算可以作为明确标注参数假设的敏感性分析，不能替代缺失的数据识别。

## 2026-09-26 执行补充：Q1→Q2 迁移门与 Q3 转移结论

### 题面要求与数据门禁的区别

- 题面要求广义标度律纳入 Q 与 p，并估计边际效用、无量纲弹性及质量与参数的替代条件；题面并未逐字规定必须从数据中分别识别“独立 p 系数”和“独立 Q 系数”。本项目采用 M0/M1/M2 嵌套模型，把 p-only 与在 p 之外加入 Q 的增量作为一种可检验实现，因此“分别识别”是该实现的证据标准，不应说成题目原文的硬性句式。
- 若 Q 是 p 的确定函数，仍可在有足够支持且形式预先限定时研究观测路径上的联合函数 h(Q(p),p)；但不能据此解释不受限制的独立偏导数或 p、Q 的分别因果效应。若优化时把 p、Q 作为可独立选择的两个决策量，则需要额外的支持数据或明示的条件假设。
- Q2 明确要求广义模型包含 `p`，并要求通过 Q1 的 `Q`、`p` 输出引入附件 A 信息；题面没有规定附件 B 的每条 Loss 行必须存有 17 维 `p` 列。因此，“B 侧逐行有 p”不是题面字段格式硬要求。
- 逐行或逐轨迹可追溯的 B 侧 `p`，是直接估计 B 来源 `p→Loss` 增量并在 B 内检验该增量的一种数据门禁。若改用 A→B 系数迁移，则须另立跨来源、跨尺度和 Loss 口径桥接假设，并以未参与拟合的来源/尺度验证；不能把 A 的预测系数直接当成 B 的估计值。
- Q3 明确要求给出结构性转移定义与识别方法，但没有指定 bootstrap 为必选方法。bootstrap 是本项目固定 Q 分支的一种稳健性方法，不能代替缺失的完整 `p,Q→Loss` 响应关系。

### 当前迁移门裁决

Q1.3 主模型以 A4/A5 的 512 个配方、17 个混合域预测 13 个领域 Loss。其 1M 同尺度 held-out 宏平均 `R²=0.618888`；冻结系数迁移到 60M 与 1B 的宏平均 `R²` 分别为 `-7.933569` 与 `-810.119586`。对应的宏平均 Spearman 分别约为 `0.831` 与 `0.727`，说明部分排序关联仍在，但跨尺度绝对预测表现明显恶化。该结果不支持直接迁移现有水平/系数；排序信息也不能单独识别 B 侧的定量边际效应。

此外，Q1 目标是 13 个领域验证 Loss，B1 当前是单列标量 `val_loss`；两者虽同为交叉熵，却没有已验证的评测域聚合权重、协议等值关系或 A→B 数值桥。A/B 实验独立这一题面事实要求提出并检验桥接假设，不能据变量名称相同就合并。

**门状态：**直接系数迁移为 `FAIL_CURRENT_EVIDENCE`；带尺度/来源校准的迁移桥为 `NOT_ESTABLISHED`。本次不新增拟合，因为现有跨尺度测试集此前已用于评估，且没有未触碰的 B 侧 `p` 与可比标量 Loss 验证集。Q1→Q2 可以保留为条件迁移情景或后续研究假设，不能写成已验证的统一经验模型。B 行级 `p` 缺失限制的是 B 内部独立估计/验证，并非题面要求的字段格式。

### Q3 当前可交付结论

固定 `Q=Q0`、不纳入 `p` 的 M0 离散分支已有 22 对预算/上下文比较，其中 17 对达到 N/D 配置改变频率至少 95% 的门槛，12 对达到成本构成改变门槛。每对情景使用 1,000 个配对轨迹 Bootstrap 复本，但独立轨迹簇只有 8 条，故结果只作该固定模型及 B1 支持网格内的稳定性证据。它支持报告“固定 Q 分支的离散配置/成本构成改变”，不支持宣称完整 Q3 的 `N,D,p,Q` 结构性转移已经完成。

## 2026-09-26 实际补证可行性核查

### B1 的 p(D) 重建

- 本地 B1 原始训练日志有 N、D、step、batch、Loss 等字段，没有来源域 token 计数或 p；checkpoint 索引只有模型、step、branch、commit。另需区分：B3 派生训练轨迹文件标有 interpolated=1，不能当作 B1 原始记录或来源 p 证据。当前本地材料不能直接计算 checkpoint 级 p(D)。
- Pythia 官方仓库确实公开了预分词训练数据、重建 dataloader 的工具和查看训练序列的脚本；各模型规模按相同数据、相同顺序训练。[Pythia 官方仓库](https://github.com/EleutherAI/pythia) [Pythia 模型卡](https://huggingface.co/EleutherAI/pythia-70m)。因此，后续从官方数据流重建仍是一条有条件路径，不应记成绝对不可能。
- 但“能还原 token 顺序”不自动等于“能得到 17 域来源标签”。目前项目中没有官方数据流到来源域的标签表，也没有已核验的 Pile 22 类到项目 17 域的逐项 token 权重交叉表。若要继续，必须同时恢复来源标签、精确对齐 checkpoint 暴露区间、登记无法映射的 token 覆盖率，并审计交叉表；单凭语料容量比例不能构造 p(D)。
- 即使恢复成功，Pythia 的共同序列只提供一条随 D 变化的累计组成路径。不同 N 的多条 Loss 轨迹不能被计为多个独立配方；须检查预先规定的组成对比在控制 log N、log D 后是否还有独立变化。若有效秩不足，停止 p 系数估计，转入受控配比实验设计。

### 独立 Q 的真实变化

- B 目录的 source manifest 将 supplementary_NQ_experiment 标为由 Pythia Loss 与 RegMix 质量信号校准的半合成补充；Q2 完整回答证据将 B6/B7 标为 semi-synthetic，B8 标为 calibrated，且 B8 固定 N,D 的 Q-Loss 方向与 B6/B7 相反。这些表可继续用于条件模型压力测试和方向敏感性，但不能充当真实 B 侧 Q 效应样本。
- Q1 的 q_huber 是冻结的操作质量接口；当前可用的 Q_covered 是由 p 确定的覆盖特征。现有真实附件没有找到在同一训练来源、同一 p/N/D 条件下独立改变并记录 Q 与 Loss 的运行。因此当前不能从这些附件估计独立 beta_Q，也不能把半合成 beta 当成实测值。

### 当前可继续的工作与停止条件

1. B1 p(D) 只做一次有明确停点的来源恢复：先取得原始 Pythia 数据流的来源标识及映射，再构建版本化 17 域交叉表；若原始数据流没有来源标识，或无法建立有覆盖率报告的来源映射，则停止该路径，不用估算语料权重冒充观测。
2. 如果 p(D) 恢复且有效秩通过，再以轨迹为聚类单位估计低维、预先声明的 p 对比；若没有足够独立 p 变化，只报告配方身份/累计组成描述，M1 仍不估计。
3. 对独立 Q，现有附件达到停止条件：没有真实独立变化。若要解除门禁，一种直接的识别设计是补充同 tokenizer、同评测集与 Loss 聚合、匹配 N/D 的受控训练运行：固定 p 改变 Q，另以多个 p 配方区分 p 效应；资源有限时先选有 Q1 证据支持的低维 p 对比，不声称恢复了完整 16 个自由度。其他数据设计若能提供可比测量及 p、Q 的独立变化，也可重新申请识别门审查。
4. 在新证据出现前，当前可形成的最完整答案是：报告 B1 的 M0 基线与验证、Q1 的 A 侧 p 结果、B6–B8 的半合成条件敏感性，并把 Q3 固定 Q 的离散优化和未知 beta_Q 阈值分析作为范围受限结果。不能把它们合并成已经估计的联合 Loss=f(N,D,p,Q)，也不能把条件最优称为经验最优。

本次核查为只读字段和来源审计，没有改动任何原始数据、没有将半合成表升级为真实观测，也没有重新拟合 Q2 或重跑 Q3。
