## 1. 与题目分析报告的关系

《题目分析报告.md》将问题二定义为：在经典标度律基础上纳入 \(Q\) 和 \(\boldsymbol p\)，估计边际效用与无量纲弹性，并讨论质量与参数的替代条件。因此，本文件中的经典基线只是完整 Q2 的前置阶段，不能单独作为 Q2 答案或“Q2 已完成”的依据。

本阶段对应广义模型在参考质量与参考配比处的基线：

\[
L=L_\infty+A N^{-\alpha}+B D^{-\beta}.
\]

基线阶段不估计质量效应、配比效应或质量与参数的替代关系。后续应拆成两步：M1 p-only（\(Loss=f(N,D,\boldsymbol p)\)）不必等待最终 Q，但当前缺少逐样本 p 联接及 Q2 的 M1 拟合器；M2 p+Q（\(Loss=f(N,D,\boldsymbol p,Q)\)）还须等待冻结的 \(Q\) 及版本号。Q1.3 的 p-only 建模结果不等于 Q2 已具备逐样本 p 或已实现 Q2 的拟合器，也不等于 Q1.1 最终质量分数 \(Q\) 已定。

题目分析报告中的数据角色合同仍然适用：B1 主拟合；B2 或 B3 至少一个用于族外或轨迹验证；B4、B5 用于跨族或文献验证；B6–B8 是半合成补充；B9–B10 只用于大尺度外推和不确定性讨论。执行前须核对实际文件与这些角色的映射，不能只凭文件名推定。

## 4. 基线模型与拟合范围

Gate 0 通过后，沿用当前实施方案中的经典主模型；本次已完成 B1 拟合，没有另起一套 B1 Scaling Law：

\[
\widehat L(N,D)=L_\infty+A N^{-\alpha}+B D^{-\beta}.
\]

拟合时保留方案已规定的正值约束、多初值、边界检查、拟合值与残差输出。应同时检查参数可辨识性和不同初值的解稳定性；若指数或 \(L_\infty\) 贴边、漂移或出现多组解，记录为模型/数据支持不足，不能仅凭训练集 \(R^2\) 判定通过。

只考虑参数项或只考虑数据项的形式可作为主模型族内的删项诊断，用于判断两项是否分别提供解释信息；不把它们扩展成新的模型搜索路线。主模型及扩展总数须遵循题目分析报告中“总模型体系不超过两个”的限制。

## 5. Bootstrap 与参数稳定性

由于同一训练轨迹中的 checkpoint 可能相关，禁止默认对 B1 每一行独立、有放回抽样。参数稳定性分析按 Gate 0 冻结的模型/训练轨迹 cluster 进行重抽样，并在报告中说明重抽样单位、有效 cluster 数和区间计算方法。

若独立 cluster 数不足以支持可靠的 cluster Bootstrap，应明确报告区间不稳定或无法可靠估计；不得退回逐行 Bootstrap 并把它描述成独立样本不确定性。可同时报告拟合多初值、参数剖面/边界行为及留出轨迹敏感性，作为诊断证据。

## 8. 明确不属于当前工作包的内容

在 Q1.1 最终质量分数 \(Q\) 尚未冻结时，以下涉及 Q 的工作不得用临时值提前定论：

- 估计最终质量分数 \(Q\) 对 Loss 的效应；
- 估计 \(Q\times\boldsymbol p\) 交互效应；
- 报告最终质量/规模弹性或质量与参数规模的等成本替代关系；
- 将该基线直接输入 Q3 并宣称联合资源配置已完成。

单独估计 M1 的配比预测效应不需要最终 Q；但当前仍需实现经确认的 Q2 拟合器，并得到与 Q2 Loss 行对应、可追溯的真实配方 p。Q1.3 的 A4/A5 配比—Loss 模型不能替代该拟合器或 B1 模型/checkpoint 级的训练配方映射。

Q1.2 的冲突模型内部结果不作为经典 \(Loss=f(N,D)\) 基线输入。后续最终质量接口如何综合 Q1.1/Q1.2，应按 Q1 的正式冻结输出执行。

## 10. 本次执行结果

基线形式为 `L = E + A*N_params_B**(-alpha) + B*D_tokens_B**(-beta)`，仅用 B1 拟合。参数点估计为：

| 参数 | 估计值 | 95% cluster Bootstrap 区间 |
|---|---:|---:|
| `E` | 1.689797563 | [1.689644998, 1.689962495] |
| `A` | 0.353980321 | [0.353843271, 0.354124939] |
| `alpha` | 0.339976582 | [0.339831484, 0.340115485] |
| `B` | 1.240305584 | [1.240160230, 1.240434051] |
| `beta` | 0.279878129 | [0.279823457, 0.279937397] |

B1 拟合内 RMSE 为 0.000146496、MAE 为 0.000105232、\(R^2=0.999999817\)。24/24 个固定初值收敛到近最优解；缩放 Jacobian 秩为 5/5，条件数约 56.38，未触发预设可辨识性警告。对 8 条完整轨迹进行 1,000 次 Bootstrap，1,000 次均成功；由于独立 cluster 只有 8 条，区间只作为稳定性提示。

留出集 RMSE：B2 为 1.2431、B3 为 0.0038213、B4 为 0.29267、B5 为 0.19760。B2 是半合成数据，B3 是插值轨迹；B4/B5 缺少共同 tokenizer/评测集口径证据，因此这些指标仅在各来源内部解读，不能跨源直接比较，也没有汇总分数。
