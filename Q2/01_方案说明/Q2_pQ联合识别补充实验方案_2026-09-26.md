# Q2 的 p/Q 联合识别补充实验方案

日期：2026-09-26
状态：实验设计与数据接收规范；尚无新增训练运行结果。

## 1. 题面判断

可见题面明确要求问题二建立同时包含 `N、D、Q、p` 的广义标度律，估计各因素的边际效应和弹性，讨论领域间替代/互补，并推导质量提升与扩大模型规模的替代条件。问题三又要求在预算下配置 `N、D、Q、p`。因此只保留固定 `Q0`、固定配方的 M0，不能作为完整答题结果；需要能把配比效应和质量效应分别识别的变化数据。

## 2. 现有证据能做什么

- B1 有 1,176 个 Loss 检查点和 8 条 Pythia 轨迹，但规模间共用数据顺序政策，且本地日志没有领域 token 计数。它支持 `N,D` 的 M0，不提供可识别的 B 侧配比变化。
- A4/A5 有 512 组配方，可支持 1M 同尺度下的来源内配比—Loss 分析；跨到 60M、1B 的预测没有通过，不能直接当作 B 标度律的配比系数。
- B6/B7 是允许使用的半合成质量响应补充，但 B7 的 360/360 个重合行与 B6 完全相同；不能把两者当成独立重复。B8 在固定 `N,D` 后仍呈现与 B6/B7 相反的质量方向，须单独报告，不能并入同一质量效应。
- 因而现有 A 侧配比数据和 B6/B7 质量数据可以作为分来源补充，不能组成同一真实训练运行上的 `(N,D,p,Q,Loss)` 联合实验。

## 3. 执行顺序

### 阶段 A：恢复既有训练记录

先向原训练/数据团队索取 dataloader 或 sampler 日志、训练配置、检查点映射和 Loss 评测配置。若能找到多个可比配方，并能从同一运行恢复质量变化，先用历史运行；不必重复训练。

每个 checkpoint 的实际累计领域 token 数优先于配置中的目标采样权重。若只能恢复目标权重，明确标记为 `p_recipe`，不要称为实际 `p(D)`。未映射领域保留为 `other`，不可静默删除后再归一化成 17 域。

**公开 Pythia 恢复路线核查：** EleutherAI 公开了 Pythia 训练数据和重建 dataloader 的工具，原则上可恢复训练批次/序列；官方说明各模型规模使用相同数据、相同顺序。[官方仓库](https://github.com/EleutherAI/pythia)；[Pythia 论文](https://proceedings.mlr.press/v202/biderman23a/biderman23a.pdf)。但本地训练日志没有来源标签，公开的随机样本查看表也只列 `Index`、各模型的训练暴露比例和 `Tokens`，不含来源域字段。[公开样本表](https://huggingface.co/datasets/EleutherAI/pile-deduped-pythia-random-sampled)。因此“有 token 顺序”仍不等于“有逐 checkpoint 的 17 域 token 数”；还需要把每个文档/序列可靠地映射回 Pile 来源并映射到项目 17 类。即使恢复成功，同一数据顺序也不能算作多个独立配方；`p(D)` 是否能在指定广义标度律下提供额外识别信息，仍要通过设计秩、与 D 的混杂和留出运行审计后判定。

### 阶段 B：历史记录不足时，做受控配方 × 质量实验

1. **独立改变配比。** 预先确定若干 17 域配方，使其在组成对比坐标上有独立变化；总训练 token 数保持一致。
2. **独立改变质量。** 对每个选定配方至少设置可区分的质量处理版本；保持各领域目标配比不变，通过领域内数据筛选/质量处理改变质量。质量评分使用冻结的 `Q1-q_huber-v1`，在训练前计算并留存处理规则。
3. **交叉安排。** 尽量让每个配方都出现于多个质量水平，使 `p` 与 `Q` 不互相决定。若只做少数配比对比，论文结论只覆盖预先指定的对比，不推广到全部 17 个域系数。
4. **控制训练与评估。** 固定或成组记录模型架构/初始化、分词器、优化器、训练顺序规则、上下文长度、验证集和 Loss 代码；条件间使用一致的 `N,D` 检查点。用独立随机种子重复关键条件。
5. **覆盖标度维度。** 若要把响应写成广义标度律，而不是单一规模的配方实验，需在多个 `N,D` 水平重复基准与代表性配方/质量条件。设计点要覆盖共同支持域。

**设计秩要求：** 17 域配比总和为 1，只有 16 个独立组成方向。若目标是估计不受正则化约束的全部 17 域主效应，在一个固定 `N,D` 下，包含截距、16 个配比方向和 1 个独立质量方向，设计矩阵至少需要 18 个线性独立观测条件；实际还需重复运行以估计噪声。完整交叉的 17 个配方 × 2 个质量水平是更容易审计的最低结构之一，但不包含重复和多尺度扩展，不能直接视为足够样本量。若训练预算有限，先选少数有题意依据的配比对比并明确收窄结论。

## 4. 需要提供的文件

四张 CSV 可分开提供，也可从原日志导出。原始日志无需预先整理；缺失字段留空并标注原因，不推算补齐。

```text
run_id,recipe_id,quality_treatment_id,model_id,model_commit,config_hash,seed,N_params,tokenizer,optimizer_config,data_version,context_length
```

### `checkpoint_loss.csv`：每个运行检查点一行

```text
run_id,checkpoint_id,step,D_tokens_cumulative,train_loss,val_loss,eval_dataset,eval_split,loss_definition,loss_code_version
```

### `domain_token_counts.csv`：每个运行、检查点、原始领域一行

```text
run_id,checkpoint_id,original_domain,project_domain_17,cumulative_tokens,source_log,mapping_status
```

### `recipe_quality.csv`：每个配方/质量处理/领域一行

```text
recipe_id,quality_treatment_id,original_domain,project_domain_17,target_sampling_weight,quality_metric,quality_version,domain_quality_score,filter_rule,data_snapshot
```

另附训练代码/配置版本、领域映射依据、验证集说明及文件哈希。配方表中的目标权重和 checkpoint 表中的实际累计 token 数分开保存。

## 5. 拟合与通过条件

按 `M0 → M1(p) → M2(p,Q)` 嵌套比较。配比用满足单纯形约束的对比/组成坐标表示；Q 的效应只在控制 `p,N,D` 后仍有独立变化时估计。训练运行作为重抽样和留出分组单位，不把同一轨迹的多个 checkpoint 当作独立重复。

开拟合前检查：

- 配方、质量处理、checkpoint、Loss 的键精确匹配；未匹配、重复和排除行单独报告。
- 17 域组成覆盖完整且实际比例和为 1；`other` 明确纳入分母。
- 配比对比设计矩阵有目标秩，且没有被 `N,D`、模型版本或质量处理完全吸收。
- Q 在控制配比、`N,D` 后仍有变化；若没有，M2 不估独立 Q 系数。
- 按配方/运行留出验证，并报告独立运行数和不确定性；只有通过门禁才计算正式边际效应、弹性及替代条件。

## 6. 当前执行边界

项目现有附件中没有按领域计数的 B 侧训练日志，也没有可直接运行新训练的脚本或模型权重。因此现在可以完成实验设计、数据模板、现有 A/B 半合成材料的分来源复核；实际受控训练必须由持有训练环境和数据加载日志的团队执行。收到上述原始文件或新实验输出后，可继续完成连接审计、设计秩门禁、M0/M1/M2 拟合、留出验证及 Q3 转移重算。未得到新数据前，不把 B6/B7 的半合成质量斜率或 A4/A5 的来源内配比系数写成 B 侧联合实证效应。

## 7. 本轮推进记录与受控实验决策

### 7.1 Pythia 来源恢复门禁结论（2026-09-26）

- 本地 B1 主表字段为 `run_id,N_params_B,D_tokens_B,...,val_loss`，没有来源域 token 计数；本地 B1–B5 p 审计为已验证 p 向量 0、与 Loss 联接行 0。本次可枚举项目文件中未发现可直接用于来源联接的 Pythia `.bin/.idx`、原始来源标签表或 sampler token 计数日志。
- 官方 Pythia 资料说明不同规模使用相同训练数据和顺序，并公开预分词数据及 dataloader 重建材料；公开数据目录中的训练数据是大体量 `.bin/.idx` 分片。公开材料不能直接替代项目需要的“来源标签—17 域映射—检查点累计 token 数—Loss”联接。即使恢复出累计来源组成，八个规模也不能当作八种独立配方；仍须检查 `p(D)` 在控制 `N,D` 后的有效变化与设计秩。
- 已有官方 Pile 组件交叉表将 22 个来源中的 17 个映射到项目 17 域，公布权重合计 75.02%；其余 24.98% 暂未映射。该权重描述公布的语料/组件份额，不是 B1 每个检查点的实际累计 token 计数。可作为新实验的配方背景信息，不能填进 `domain_token_counts.csv` 冒充观测。
- Q1 的 17 域映射中有 3 个 direct、3 个 near-direct、11 个 inferred；现有证据没有证明 `Q1-q_huber-v1` 能直接为任意 Pile 训练文档打分。开训前须先验证评分器可移植性：复现冻结版所需的输入特征与预处理，报告逐域覆盖、指标可计算率、跨域量尺适用性及复算一致性。门禁通过后，才可对实际训练文档打分并按实际训练 token 权重聚合；门禁未通过时，只分析可评分范围，或将新增评分明确定义为新版本 Q 并单独验证，不能称为冻结 Q1 分数。未覆盖来源不补零或套用 inferred 域分数。

**门禁决定：** 现有公开来源恢复只通过“有条件重建”这一技术可能性检查，未通过生成 B1 实测 `p(D)` 的数据门禁；不下载大型 token 数据来替代缺失的 source 标签与检查点交叉表。若训练方可提供原始 dataloader/source-token 日志，则按阶段 A 继续；否则转阶段 B 受控实验。

### 7.2 受控实验的两个可交付范围

**范围一：低维、可执行的 p/Q 联合效应。** 预先选定少量有题意依据且 A4/A5 有配方支持的组成对比，只把 A 侧结果用作候选设计信息。对一个配比对比，在同一 `N,D`、模型版本、训练配置、tokenizer、评测集和 Loss 代码下，设置参考配方与替代配方，并与两个经过验证的 Q 处理水平交叉，形成至少 `2 × 2` 条件；质量处理在各领域内部筛选/抽样以保持目标 p。Q 评分器通过可移植性门禁后，在最终入训语料确定后、开训前逐文档评分，并按计划 token 数计算目标 Q；训练过程中再依据实际 dataloader 暴露量，逐检查点核验实际 `p(D)` 和 `Q(D)`。长度均衡、去重等伴随处理须固定或逐项记录。该设计估计预注册质量筛选策略及其 Q 变化对应的效应；若要把它解释为 Q 标量本身的独立因果效应，还须有证据排除筛选带来的其他文本变化。该设计只识别预注册配比对比和试验 Q 区间内的有限效应/局部交互，不代表 17 域全方向效应。两个 Q 水平给出有限差或弧弹性；若报告连续导数 `∂L/∂Q`、点弹性或一般替代斜率，应增加 Q 水平并预先指定可验证的响应函数，否则把结果标为该区间的有限差与有限区间替代量。所有条件还须覆盖共同的多个 `N,D` 水平，才能估计并验证广义标度律中的尺度关系。

为避免把未映射来源隐去，实际记录使用完整 token 分母，同时保存 17 域条件配比、17 域实际份额和五个未映射来源各自的实际份额。75.02% / 24.98% 是已公布组件权重的交叉表结果，只能作候选参考，不是新实验的实际目标或 Pythia 检查点份额。实验须另行预注册目标 `other` 总占比及五个来源的内部比例，并由实际 token 计数核验；若不能固定其内部构成，则须拆分建模或排除不匹配条件。17 域配比在 `other` 固定时解释为映射来源质量内的条件配比，结论限定于该背景。

**范围二：全 17 域主效应。** 17 个份额受和为 1 约束，只有 16 个独立组成方向。在固定 `N,D`、固定 `other` 及其内部构成、且只拟合加性 p/Q 主效应（无 p×Q 交互和额外非线性基函数）的规格下，加入截距、16 个配比方向和一个独立 Q 方向，设计矩阵至少需要 18 个线性独立条件；这是代数秩下限，不是足够样本量。若纳入交互、额外非线性项、可变 `other` 或多个尺度交互，必须按实际参数化重新计算目标秩。设计仍需独立质量变化、重复运行和多个 `N,D` 水平。若训练预算无法支撑，不以半合成记录或正则化系数替代缺失的方向信息，应采用范围一并明确报告限制。

### 7.3 拟合和停止规则补充

1. 先核验 run/checkpoint 键、来源 token 计数、五个未映射来源的目标与实测份额、Q 评分器门禁/版本/覆盖率、Loss 口径、模型及训练配置和实际配比闭合；未联接或测量未覆盖行不得进入拟合。
2. 在固定或显式控制 `N,D`、模型版本、训练配置、tokenizer、评测口径及全部背景来源构成后，检查预注册配比对比矩阵的目标秩、剩余自由度、独立 run 重复数，以及每个 p 水平内 Q 的覆盖重叠。仅有残余变化不足以宣称 p/Q 可识别；Q 若由 p 决定或两者缺少共同支持，则停止相应独立项。
3. 在分析前指定估计对象、效应区间、独立 run 数、重复种子和留出分组。训练运行/配方是验证分组单位，检查点只用于描述轨迹；同一运行的检查点不能跨训练与留出集，不以 B1 训练内拟合或同一轨迹插值作为独立验证。
4. 只有门禁通过且留出验证支持时，才输出预注册 p 对比的边际效应；Q 有足够处理水平且响应函数通过检查时输出点弹性及等 Loss 替代斜率，否则报告区间有限差。通过验证的响应面再交给 Q3 做结构性转移分析。

**当前可执行状态：** 本工作区没有原始训练团队的 sampler/source-token 日志、新受控训练运行、可直接启动训练的模型权重或训练脚本。故本轮完成的是来源恢复门禁和受控设计定稿；数值 p/Q 联合效应需由可访问训练数据与算力的一方产生新记录后才能估计。`Q1-q_huber-v1` 是操作性质量指标，须携带 Q1 的人工核查范围和跨域量尺限制，不能表述为无误差的真实质量。
