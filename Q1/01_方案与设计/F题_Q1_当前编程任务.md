## P0：Q1.3 只读数据审计入口

### 目标

从现有 Q1.3 数据读取代码扩展一个 audit-only 入口，例如：

```powershell
python src/f_q1_3_mixture_loss.py --mode audit
```

该入口只核对附件结构、键和训练数据质量，不拟合、不比较模型、不生成预测，也不使用 Q1.1/Q1.2 产物。实现时优先复用现有函数，避免复制一套 loader。

### 审计范围

1. **固定数据角色**：按题目文件角色登记 A4/A5 训练、A6–A11 检验、A12–A15 估算表一致性检查。遵循既有分工，不重新随机划分，不把 A12–A15 放入训练。
2. **严格 Schema**：核对 `index`、17 个配比列和 13 个 Loss 列的规范名称及顺序；拒绝重复列名、缺列和非预期列。字段名来自题目数据合同，不从首个文件推断全局标准。
3. **配对键**：核对每对配比表与 Loss 表的 `index` 唯一性、行数和键集合一致性；输出缺失键、额外键和重复键计数。
4. **A4/A5 训练值审计**：报告空值/非法值、非有限值、负配比、零和行、逐行原始配比和、零分量数、重复配方；若同一配方对应不同 Loss，列出目标级差异摘要。
5. **外部文件隔离**：对 A6–A15 只检查文件角色、Schema、`index` 键和哈希，不输出其 Loss 分布、误差或用于模型选择的统计摘要。全量指标评价仍由后续冻结模型流程完成。
6. **来源记录**：记录输入路径、角色、文件大小、SHA-256、审计脚本哈希、运行时间和审计状态。

### 明确不做

- 不计算或保存闭合后的配比；只记录原始行和与合法性标记。
- 不补零、不加伪计数、不删异常、不合并重复样本、不做标准化或特征工程。
- 不读取质量分、冲突分、模型预测或人工评分。
- 当前 `p-only` 路线不使用 A16 质量域映射；暂不把 A16 纳入此审计入口。
- 不导出重复的全量 `q1_3_base_rawparsed.csv`。

### 输出

建议只产生精简、机器可读且便于复核的文件：

```text
results/q1_3/audit/
├── audit_summary.json
├── file_roles.csv
├── pair_integrity.csv
└── train_composition_qc.csv
```

### 完成条件

- `audit` 命令可独立运行，不触发任何拟合或预测函数。
- A4/A5 的值审计覆盖全部训练行；A6–A15 只产生约定的结构与键检查。
- 标准列名、重复表头和配对键错误均能明确报告并返回失败状态。
- 原始附件与公共预处理冻结产物哈希不变。
- 审计输出能追溯输入文件和审计代码版本；同一输入重复运行不会改变审计结论。

## P1：Q1.1 盲评工具（门控启动）

当 Q1.1 确认执行原文双人评审，并已有冻结的待评样本名单后，再实现轻量的匿名导出与评分回收工具。工具只消费样本名单和原始文本，不生成抽样名单，也不接触候选质量分、指标值或来源标签。

最小功能：

- 为评审文本生成随机匿名 ID，并将 ID 对照表单独保存，不随评审文件分发。
- 两名评审获得独立随机顺序的文本与已确认评分表。
- 回收时核对匿名 ID、评分范围、缺失和重复记录，并输出原始配对评分表。
- 一致性统计按 Q1.1 已确定的评分尺度与分析方案实现；不在工具中选择质量评分模型。

样本分层与名单由 Q1.1 建模流程冻结后提供。名单未冻结时，不做具体评审数据导出。
