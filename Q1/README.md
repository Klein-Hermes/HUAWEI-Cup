- Q1.1：全量候选质量分、稳健性结果和 30 条双人微型评分核查已生成。人工核查未区分 q_equal/q_huber；项目负责人已明确选择 `q_huber` 作为带限制的操作主 Q，`q_equal` 保留为敏感性分，正式接口已生成。该选择是操作性决定，不是人工评审胜出。机译、同序回收、独立评分过程未核实、A2/A3 原文映射及 7 个 `rps_*frac*` 字段语义/单位均限制结论。

- 公共预处理：A1–A3 的 q1-common-v1.1 结果及数据质量报告已归档。
