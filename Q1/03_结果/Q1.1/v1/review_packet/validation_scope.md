# Q1.1 原文验证范围

本轮生成 A1 盲评样本 793 条，分层为 A1 来源域 × Q_equal 三分位 × 宽 Unicode 完整性标记。每层最多抽 25 条；评审材料与 `restricted_id_mapping.csv` 分开保存。

当前 A2/A3 扩展质量信号文件不含 content，工作区也未提供与这些评分 ID 一一对应的原文映射。因此本包只支持 A1 原文效度评审，不能据此声称 A2/A3 原文已验证。取得可追溯原文及 ID 映射后，才可按预注册规则补充扩展集盲评。

原文评分器来源和 22 个上游信号生成/规范化流程仍未从本地附件中追溯到可重算实现；Unicode 排除校准敏感性不能证明上游预计算信号免受文本影响。
