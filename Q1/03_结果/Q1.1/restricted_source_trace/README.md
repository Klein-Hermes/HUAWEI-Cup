# A2/A3 部分原文链接表（内部核对用）

`a2_a3_partial_text_linkage.csv` links some A2/A3 quality-signal rows to text already present in the local A1 raw sample. It contains raw IDs and source paths, but no text. Keep it separate from all reviewer materials.

The linkage was checked by exact ID, matching `_source_domain`, and equality of all seven RPS values within absolute tolerance `1e-9`. The table contains only matched rows: 1,419 A2/arXiv and 10,000 A3/GitHub. It does not imply that the remaining A2/A3 rows have text or that extended-set human validity has been assessed.
