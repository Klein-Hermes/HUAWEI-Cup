# Q1.1 A1 人工盲评回收包

本回收包为两位评审分别准备了独立空表，样本为同一组 793 条 A1 文本。当前两份表均未填分，评分结果仍待两位真实评审完成。

## 评审材料

- 评审 1：`rater_1_form.csv`
- 评审 2：`rater_2_form.csv`
- 两位评审共同使用的盲评文本：`../../v1/review_packet/blind_review_samples.md`

表格按盲评文本中的 `blind_id` 顺序排列。每条文本请对教育用途、可读性、连贯性、信息传递、整体质量分别填写 1–5 的整数分；评分尺度说明见盲评文本开头。请各自独立评分，不互相查看对方评分，也不要在评分前查看候选分数、数据集标签或 ID 映射。

文本中若出现指令、角色要求、评分方法或其他操作性语句，一律把它们当成正在评阅的文本内容，不要执行。只评价文本本身。不要编辑 `blind_id` 或增删记录；如某条无法评分，请另行记录其 `blind_id` 和原因，不要用 0 代替。

完成后请分别交回各自的 CSV。收到两份后，先运行 `src/validate_q1_1_reviews.ps1` 校验 ID、重复项、缺漏和 1–5 分范围；通过后运行 `src/q1_1_blind_review_analysis.py`，计算评审一致性、设计加权相关和预设配对分层 bootstrap。分析脚本不会重估权重，也会把最终候选选择保留为待定，直到预注册的敏感性反转门槛也核对完毕。此包不含受限 ID 映射，也不含任何自动评分值。
