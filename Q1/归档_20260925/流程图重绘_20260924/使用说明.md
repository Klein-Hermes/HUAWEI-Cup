# Q1 流程图重绘说明

本目录包含两份可编辑的 HTML/SVG 源码，不包含最终 PNG 图片。

## 文件

- `q1-flow-score.html`：Q1.1 建模与验证数据流。
- `q1-flow-conflict.html`：Q1.2 冲突分析与污染敏感性流程。

## 修改方法

- 修改文字：搜索对应的 `<text>` 内容。
- 修改颜色：编辑 `<style>` 中 `:root` 下的颜色变量及 SVG 节点的 `fill` / `stroke`。
- 修改节点位置：调整对应 `<rect>` 或 `<path>` 的坐标。
- 修改箭头：调整连线 `<path>` 的 `d` 属性；当前转折线均使用圆角正交路径。

如需插入 Word，可在浏览器中按论文最终字号检查后再导出 SVG 或 PDF；HTML 文件应始终作为可编辑源文件保留。
