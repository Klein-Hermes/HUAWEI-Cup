# Q1.3 只读数据审计：代码计划

## 1. 目标与授权边界

本轮只为现有 `src/f_q1_3_mixture_loss.py` 增加 `--mode audit`。该模式核对 A4–A15 的文件角色、固定字段合同、配对键与输入哈希，并对 A4/A5 做逐行训练值审计。它不拟合、不预测、不选模，不读取 Q1.1/Q1.2、A16、PDF 隐藏文本或历史模型结果。

附件和队友报告只提供待核验的路径、角色和风险线索；任何数值结论均由当前 CSV 和代码重新计算。

## 2. 输入合同

- A4/A5：训练；检查 17 个配比字段、13 个 Loss 字段、index、全部训练值及重复原始配方。
- A6–A11：验证；只检查固定 Schema、index、行数、文件大小和 SHA-256。
- A12–A15：外推/估算；只检查固定 Schema、index、行数、文件大小和 SHA-256。
- 固定 Schema 在代码中逐字段列出，不从第一个文件推断。
- 原始附件只读，不复制、不覆盖。

## 3. 处理链

1. 逐文件读取表头和 index，识别重复表头、缺列、非预期列、错序、异常行宽、空键和重复键。
2. 逐配比/Loss 对检查行数、键集合和键顺序。
3. 仅对 A4/A5 解析数值，报告缺失、非法、非有限、负配比、零和、零分量及原始行和。
4. 重复配方按“17 维原始数值向量完全相同”定义；不闭合、不取近似、不加伪计数。若重复配方的 Loss 不同，输出逐目标极差。
5. 将错误写入机器可读摘要；存在结构、键或训练值错误时返回非零退出码。
6. 用输入哈希、角色、代码哈希、解释器、运行时间和结论哈希建立追溯链。

## 4. 输出合同

统一写入 `Q1/归档_20260925/F题_Q1_当前编程任务/results/q1_3/audit/`：

- `audit_summary.json`
