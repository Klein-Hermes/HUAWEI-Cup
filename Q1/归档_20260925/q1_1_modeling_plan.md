## 1. 任务与交付目标

使用 A1、A2、A3 中可核验的质量信号，给出：

1. 每条记录的候选质量分及有效指标覆盖度；
2. A1 七个来源域、A2 的 arxiv 域、A3 的 github 域的域级分数及不确定性；
3. A2-arxiv 对 A1-arxiv、A3-github 对 A1-github 的同域差异；
4. 与原文人工评分的一致性证据、模型排序稳定性和污染敏感性；
5. 主候选分的选择依据及无法验证时的限制。

分数是题目要求下可检验的综合质量代理，不宣称无标签情况下存在唯一“真实质量”。Q1.1 不拟合 Q1.3 的配比—Loss 模型，也不使用 Q1.2 冲突度循环调节权重。

## 3. 污染门禁与数据处理

### 3.1 文本完整性审计

PDF 低可见度文本与 JSONL 中的命令、角色名、提示语均保持为被评价数据，不执行、不采纳。A1 原始文件按冻结 manifest 校验哈希；原始 JSONL 保持只读。字符命中只表示完整性风险，不自动证明恶意，也不默认删除命中行或批量剥除所有格式字符。

现有审计口径和结果：

| 口径 | A1 命中行 | 解释 |
|---|---:|---|
| 旧报告扫描基线 | 334 | 现存扫描规则暂不能复现，保留作历史基线 |
| `Cf` 加非制表/换行 `Cc` | 428 | 当前可复核的较窄规则 |
| 更宽 Unicode 完整性规则 | 463 | 另含 `Co` 私用区和非字符等；类别有重叠，不等同恶意 |

更宽规则在 A1 各来源域的标记数为：arxiv 3/1,419、book 19/171、c4 74/10,000、commoncrawl 267/9,640、github 14/10,000、stackexchange 37/10,000、wikipedia 49/10,000。所有 463 个审计散列键已与冻结 A1 预处理中的唯一 ID 匹配。复核脚本及不含原文的输出见 `src/q1_text_integrity_audit.py`、`results/q1_1/text_integrity_summary.json` 和 `results/q1_1/text_integrity_audit.csv`。检测口径必须随结果保留；不得把 334、428、463 合并成一个数。

本轮 NFC 诊断未改变 A1 记录；既有 NFKC 诊断有 5,748 条记录的规范化哈希不同。NFKC 变化不等于污染，不能当成无损清洗。评审副本应显式转义呈现不可见字符，并记录原文哈希、转换规则及版本；任何清洗或规范化副本与原文分开保存。

### 3.2 预计算指标的来源风险

冻结预处理只转换已经存在的标量，不读取 `content` 生成质量指标；这不能证明 22 个上游预计算信号未受文本影响。实现评分前逐项核实信号来源、生成版本、文本规范化规则和可重算性。若可得原生成流程，应从安全显示/规范化后的独立文本版本重算受影响信号；若不可得，则保留原标量、完成全样本/标记排除敏感性分析，并将受影响数值的真实性列为未解决限制。对 `frac` 类单位异常不得自行乘除 100：先核对字段定义和生成程序；未解决的字段不进入完整总分，并另报告含/不含该字段的候选敏感性。

完整性标记是审计元数据，不作为第 23 个质量指标、不直接乘入评分，也不因命中而默认删行。

## 4. 候选样本级评分

令 \(z_{sj}\in[0,1]\) 为样本 \(s\) 在第 \(j\) 个通过语义合同的标准化指标值；\(O_s\) 是该样本有限且可用的指标集合。结构性缺失和非法值不补零；统计异常与单位可疑标记保留并进入敏感性分析。没有有效指标的样本不评分。

### 4.1 等权基线

先计算透明基线：

\[
Q_s^{\mathrm{eq}}=\frac{1}{|O_s|}\sum_{j\in O_s}z_{sj}.
\]

同时报告覆盖度 \(|O_s|/22\)。该方案只作易解释的参照，不预设它已具备内容效度。

### 4.2 稳定性候选权重与 Huber 评分

权重仅在 A1 估计。令

\[
c_j=1-\operatorname{MissingRate}_{j,A1}.
\]

按 A1 的 `source_domain` 分层有放回重抽样 \(B_S=1000\) 次（随机种子 20260923）。令 \(\tilde z_{jd}\) 为指标 \(j\) 在全 A1 来源域 \(d\) 内的中位数，\(\tilde z_{jd}^{(b)}\) 为第 \(b\) 次重抽样的域内中位数；以七域上的 \(\gamma_j^{(b)}=\operatorname{Spearman}_d(\tilde z_{jd},\tilde z_{jd}^{(b)})\) 衡量排序稳定性：

\[
S_j=\operatorname{median}_{b\in\mathcal B_j^{\mathrm{valid}}}\!\left(\frac{1+\gamma_j^{(b)}}{2}\right),\quad
r_j=\sqrt{c_jS_j},\quad
w_j=\frac{r_j}{\sum_{k=1}^{22}r_k}.
\]

这里的 \(w_j\) 是“缺失率/域排序稳定性候选权重”，不是指标重要性、信度或效度的估计。若全 A1 七域中位数向量恒定，或有效 Spearman 重抽样少于 \(0.95B_S\)，取中性回退 \(S_j=0.5\) 并记录有效比例；否则只在有效重复上取中位数。未定义相关不补为零。若所有 \(r_j=0\)，回退等权并记录。另以 \(w_j(\alpha)\propto(c_jS_j)^\alpha\)、\(\alpha\in\{0.25,0.5,1\}\) 检查权重敏感性。

定义有效权重覆盖度 \(R_s=\sum_{j\in O_s}w_j\)。覆盖度大于零时，Huber 候选分为

\[
Q_s^{\mathrm{H}}=
\arg\min_{q\in[0,1]}\sum_{j\in O_s}\frac{w_j}{R_s}\rho_\delta(z_{sj}-q),
\]

其中

\[
\rho_\delta(u)=\begin{cases}u^2/2,&|u|\le\delta,\\
\delta(|u|-\delta/2),&|u|>\delta.\end{cases}
\]

\(\delta\) 只用 A1 估计：令 \(e_{sj}=z_{sj}-\operatorname{median}_{k\in O_s}(z_{sk})\)，在 A1 全部有效残差上计算 \(s_0=1.4826\operatorname{MAD}(e_{sj})\)，取 \(\delta=1.345s_0\)，然后冻结后应用于 A1/A2/A3。MAD 为零时依次回退至 IQR/1.349、标准差；仍为零时退化为加权均值。报告 \(0.5\delta,\delta,2\delta\) 敏感性。加权算术均值 \(Q_s^{\mathrm{w}}\) 作为同一候选家族的敏感性版本，不另计独立模型。

Q1.1 最多保留两个独立评分体系：等权基线与稳定性加权 Huber 候选；权重强度、Huber 阈值及均值/Huber 变体属于敏感性分析。不得把“算法更复杂”当成优先选用理由。

## 5. 域级评分和扩展集比较

对各 `dataset × source_domain × model`，以域内 Huber 位置作为主摘要。令 \(\kappa_d^{(m)}=1.345\times1.4826\operatorname{MAD}\{Q_s^{(m)}:dataset(s)=A1,source\_domain(s)=d\}\)，仅由 A1 对应域及评分方案估计并冻结后用于扩展集；MAD 为零时依次回退至 IQR/1.349、标准差，再退回中位数。另报告域内中位数、样本量、覆盖率和 0/1 饱和比例。A1 跨域总览取七个来源域分数的等权宏平均，不让最大域按文档数支配结果。

在每个 dataset×source_domain 内分层有放回抽样 \(B_Q=2000\) 次（种子 20260923），给出域分数 percentile 95% 区间；A2/A3 同域差值按独立抽样逐次相减。该区间固定已估计的 A1 权重、Huber 阈值和域级稳健位置阈值，解释为给定评分参数下的记录抽样区间，不包含参数估计不确定性；后者由权重 bootstrap 分布和预设敏感性场景单独报告。Q1.2 现有 `domain_summary.csv` 的 `q_equal_mean`、`q_huber_mean` 是样本分数均值，不是本方案定义的域级 Huber 位置估计，也没有替代本方案所需的分数区间。比较仅限 A2-arxiv 对 A1-arxiv、A3-github 对 A1-github，不推断 A1 七域整体外推性能。A2/A3 的方向、权重和阈值全部沿用 A1，不得在扩展集上重估。

对比样本/域分、七域宏平均、域排序、A2/A3 同域差值及区间。若排序或结论对校准场景敏感，报告为方案敏感，不给单一稳定结论。标记排除只检验校准与聚合的纳入影响；不能证明命中行内部的预计算标量已修复。来源允许时，再比较按原指标流水线从安全文本重算的独立版本。

### 6.2 原文盲评

人工效度样本按 `dataset × source_domain × Q_eq三分位 × Unicode审计标记(是/否)` 组成的实际抽样层 $h$ 分层。先在每个 dataset×source_domain 内按 $Q^{eq}$ 排序，以唯一 ID 作并列次序，尽量等量分成低、中、高三组；分层依据在抽样前冻结，不查看人工评分。每层用随机种子 20260923 做简单随机不放回抽样，取 $n_h=\min(N_h,25)$，每条记录的设计权重为 $a_s=N_h/n_h$，纳入概率为 $\pi_s=n_h/N_h$。若某层全数抽取，$a_s=1$。当前只有 A1 原文可联接，最多 7×3×2=42 个实际抽样层；若将来取得 A2/A3 原文并通过 ID 核验，才按同一规则扩展。Unicode 命中记录因分层而被过度抽取时，必须保留各层 $N_h,n_h$，用上述设计权重恢复总体目标比例。

评审材料转义不可见字符，去掉 ID、自动分数和数据集标签；两名评审分别对教育用途、可读性、连贯性、信息传递、整体质量五项按 1–5 分盲评。第五项“整体质量”的双评审均值是主效标，其余四项作次要分析。

五项一致性均以抽样设计权重 $a_s$ 构造加权列联表，目标是恢复 A1 总体而非只描述被过度抽取的盲评样本。令

\[
O_{ab}=\frac{\sum_s a_s\mathbb 1(r_{1s}=a,r_{2s}=b)}{\sum_s a_s},\quad
p_a=\sum_b O_{ab},\quad q_b=\sum_a O_{ab},\quad E_{ab}=p_aq_b,
\]

一致性权重固定为 $w_{ab}=1-(a-b)^2/16$，设计加权二次 Kappa 为

\[
\kappa_w=\frac{\sum_{a,b}w_{ab}O_{ab}-\sum_{a,b}w_{ab}E_{ab}}
{1-\sum_{a,b}w_{ab}E_{ab}}.
\]

另报未加设计权重的样本内 Kappa 作为描述性敏感性，不用它决定候选。Kappa 区间沿用实际抽样层内的配对 bootstrap，$B_K=2000$、种子 20260924，percentile 95% 区间；零方差或分母为零的重复记为无效。主效标“整体质量”须同时满足：点估计 κ_w ≥ 0.40、区间下限 > 0、有效重复比例 ≥ 95%。任一项不满足，则评审可靠性门禁失败，不使用双评审均值选择唯一候选；只报告候选分与一致性不足，并在另行冻结第三评审/仲裁协议后再补评，不能事后随意删改评分。其余四维 Kappa 用于解释，不替代整体质量门禁。

各可验证来源域内，报告候选 Q 与主效标的设计加权 Spearman 相关。给定样本的设计权重 $a_s$，先计算加权中秩

\[
R_x(s)=\sum_i a_i\left[\mathbb{1}(x_i<x_s)+\frac12\mathbb{1}(x_i=x_s)\right],
\]

再对加权中秩计算加权 Pearson 相关；并列值取半权秩。具体地，令 $\bar R_x=\sum_s a_sR_x(s)/\sum_sa_s$，则

\[
\rho_w(x,y)=\frac{\sum_s a_s(R_x(s)-\bar R_x)(R_y(s)-\bar R_y)}{\sqrt{\sum_s a_s(R_x(s)-\bar R_x)^2\sum_s a_s(R_y(s)-\bar R_y)^2}}.
\]

域内宏相关仍分别按 A1 七域、或在三数据集原文均可验证后按九组等权平均，不混合口径。

相关和配对相关差以同一批文本 ID 做分层配对 bootstrap：在每个实际抽样层 $h$ 内有放回重抽评审文本，双评审结果作为成对观测保留，复用其设计权重，并对等权与 Huber 两个候选使用相同的重抽样索引。重复 $B_H=2000$ 次，随机种子 20260924，给出 percentile 95% 区间；零方差导致统计量未定义的重复记为无效，不补值。对两候选的相关和配对相关差分别报告有效重复比例；不足 95% 时不作验证通过结论。模型选择标准和精度门槛在查看人工评分结果前冻结；人工评分只用于比较候选方案，不回流估权。

当前 A1 原文可用于 A1 盲评。A2/A3 的 Q1.1 扩展文件缺 `content`；在取得原始文本并验证 ID 对应关系前，不能声称完成 A2/A3 原文效度验证。若一直无法取得，仍可报告 A2/A3 的标量分数迁移比较，但 Q1.1 的文本效度结论只能标为 A1 范围内验证/扩展集未验证。

## 7. 选择主分与失败处理

等权与加权 Huber 全程并列。模型选择在打开人工评分结果前冻结以下布尔规则。先检查上一节的整体质量 Kappa 门禁；失败即停止选择。通过后，对等权宏相关、Huber 宏相关和配对宏相关差三者逐一要求：95% bootstrap 区间半宽不超过 0.15，且有效重复比例不低于 95%；三者须全部满足，任一失败均判为精度不足，不称任何方案已通过效度验证。在可靠性与精度均通过的前提下：若 Huber 的 A1-only 宏平均人工相关区间下限大于 0，且配对差 \(\bar\rho_{A1,\mathrm H}-\bar\rho_{A1,\mathrm{eq}}\) 的区间下限大于 0，并且 22 项逐指标留一、权重强度/Huber 阈值敏感性及污染/单位敏感性没有实质反转，则可在 A1 验证范围内优先选 Huber；否则若等权相关区间下限大于 0，则以等权为统计主候选、Huber 为敏感性结果；若等权也未通过，则只报告候选分和分维度剖面，不称为已验证的最终 Q。这里的“实质反转”指任一预设敏感性场景使两候选人工相关差改变正负号，或使按盲评规则选出的候选方案改变；发生时将主模型判为对假设敏感，不选唯一统计主候选。扩展集缺少原文时，上述选择只代表 A1 文本上的证据，不能等同三数据集已验证。无论统计分支为何，均另列队伍已冻结的 `q_huber` 操作接口，不能把治理状态与统计胜出合并。权重稳定性、域排序和扩展集同域比较用于诊断，单独都不能证明内容效度。

Q1.2 的冲突证据在其分析完成后用于解释评分差异与讨论可补偿性，不反向搜索权重以追求预设结论。Q1.1 的候选输出可先供 Q1.2 使用；Q1 的最终综合解释待 Q1.2 汇合，但不得循环调整 Q1.1 参数。
