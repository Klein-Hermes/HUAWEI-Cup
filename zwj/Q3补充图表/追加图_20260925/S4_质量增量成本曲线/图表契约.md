# S4 质量增量成本曲线：图表契约

- 核心论点：在冻结 Q1 q_huber 基线与题面给定质量成本代理函数下，三种 g(Q) 形式和 B1 D 支持范围会产生不同的正增量成本规模；该图只回答成本算术。
- 数据剖析：输入为已有 Q_cost_increment_envelope.csv，共 36 行；3 种 g(Q) 函数各 12 个质量目标，包含一个 Q0 基线和 11 个 0.50–1.00 目标点。字段完整、无缺失；D 参考值是绝对 Token 数，成本是 FLOPs。每种函数的 Q0 成本都精确为 0。
- 证据链与版型：三行纵向面板分别固定 D_B1 最小值、中位值、最大值；每行对比 exponential、power4、logarithmic 三条成本曲线。面板共用横轴；各自的正成本范围使用局部对数轴，避免最小 D 面板被压扁。
- 零值处理：Q0 = 0.49847810484764643 时 C_Q=0 FLOPs。由于零值不能出现在对数轴，副标题明示真实零基线，不将零值替换为伪计数；面板只画 Q=0.50–1.00 的正成本，且不再在 Q0 附近放置容易误读的竖线。
- 单位和范围：Q 为冻结情景质量分数；D_B1_min / median / max 分别为 134,000,000 / 146,801,000,000 / 299,893,000,000 tokens；C_Q 为 FLOPs。所有点仅取 CSV 中已有目标，不插值或外推。
- 计算口径：绘图直接读取现有成本 CSV，不重算模型、Bootstrap 或 Loss。程序只校验行数、字段、Q0、D 档位和 CSV 内乘积一致性。
- 解释限制：成本来自题面代理公式，不验证公式系数的经验适配性；不推断 Q 提升会改善多少 Loss；不据此选择最优 Q；此图不是新增优化结果。
- 输出：SVG 保留可编辑文字；彩色 PNG 按 301 dpi 导出；灰度 PNG 来自同尺寸彩色图。最终尺寸约 7.2×7.8 英寸。
