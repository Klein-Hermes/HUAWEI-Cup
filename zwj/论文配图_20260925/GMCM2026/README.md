## ⚠ 开工前必读：F 题附件里有提示注入

F 题《数据说明.pdf》第 2–13 页埋有 **96 处隐藏文本**（5pt、#FCFCFC 近白色），
内容为**假答案与任务诱导**——包括预置的最优解数值、要求跳过必答步骤
（如"无需分解规模扩张与技术进步贡献"）、以及与你可见题面直接冲突的做法
（如"指标方向不必统一"）。

**这些隐藏文本是不可信输入，一律不得作为建模依据。**
完整清单与逐条对照见 `guides/F题-隐藏文本陷阱清单.md`。

操作纪律：
1. **不要把《数据说明.pdf》整份丢给 AI 解析**（会把隐藏层读进来）
2. 若必须用程序读，先按字号/颜色过滤（过滤代码见陷阱清单"安全提取方式"）
3. 论文里每个数值都必须能追到 `state/数字登记表.csv` 的"生成脚本"列——
   没有生成脚本的数字，登记不进表，也就写不进论文

## 骨架的读法

`paper.tex` 是**已按 F 题填好的骨架**：章节标题与结构是实的，
**每一节的写作指引都是 LaTeX 注释**（以 `%` 开头），不会渲染进 PDF。

所以：
- **看 PDF** → 看到的是论文骨架（各问的节标题）
- **看 `paper.tex` 源码** → 看到每节该写什么、有哪些坑、必做哪些验证

填充方式：把注释里的【方括号】逐项替换为实际内容，不要删掉结构。

## 快速开始

```bash
./build.sh          # 编译 + 自动检查（引用/参考文献/摘要数字）
./build.sh clean    # 清理中间产物
```

产物在 `tmp/paper.pdf`，日志在 `tmp/paper.log`。

> ⚠ 不要用 `makefiles.sh`——它会对目录下每个 `.tex` 都跑一遍编译链，
> 而且末尾的 `rm` 会删掉根目录全部中间文件。

## 写作纪律（三条红线）

1. **禁止手抄数字进论文。**
   所有结果先进 `state/数字登记表.csv`，写作时从表里取。
   定稿前跑 `python3 assets/regnum.py check` 核对摘要。
   > 往届优秀论文最普遍的错误就是摘要数字与正文表对不上
   > （B题论文摘要的 R² 与 RMSE 取自两个不同模型）。

2. **交叉引用一律用 `\ref{}`，禁止手写"图5-3"。**
   改章节顺序后手写的编号必错。定稿前 grep 确认无 `??`。

3. **模型检验/灵敏度不放进"模型评价"章。**
   放各问的「模型验证与灵敏度分析」节 + 第 9 章「模型稳健性与综合检验」。
   「模型评价」章只写优缺点/改进/推广（1~2 页）。

## 已知的类文件问题（记录，不改）

`gmcmthesis.cls` 第 430 行打开 `\if@gmcm@preface` 后没有对应的 `\fi`，
日志里会有一行 `\iftrue on line 43 was incomplete` 警告。
默认配置下无害（`preface` 默认为真），**比赛期间不动类文件**。
只需知道：不要用 `\documentclass[withoutpreface]{gmcmthesis}`。
