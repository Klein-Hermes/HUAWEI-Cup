# 论文版图注建议

论文原有题注可以继续使用。以下补充语句用于交代制图时从图面移入题注的解释边界。

| 图文件 | 建议补充到题注的说明 |
|---|---|
| `q1-cross-scale.pdf` | (a) 为宏平均 RMSE，(b) 为宏平均 Spearman 秩相关；两项指标量纲不同，故分面展示。1M 为同尺度测试，60M 与 1B 为跨尺度测试。 |
| `q1-conflict-external.pdf` | 95% 区间跨过 0 时，当前结果未检出方向性差异。 |
| `q2-m0-marginal.pdf` | 区间相对图线较窄，图中不单独展开；面板展示的点估计与边际效应口径保持不变。 |
| `result_q2_p_gate_audit.pdf`（补充图，论文正文暂未引用） | 当前审计材料中没有已核验且逐行连接到 Loss 的 17 维 p 向量，因此正式 B 侧 p-only 拟合尚不能启动。矩阵中的“0”仅指已核验并联接的记录数，不表示真实训练配比效应为零。 |
| `q3-resource-dashboard.pdf` | 图中只连接给定预算与上下文情景；固定 $Q=Q_0$ 时质量成本份额为 0，最高预算点受 B1 支持网格上界约束。 |
| `q3-bootstrap-stability.pdf` | Bootstrap 基于 8 条 B1 轨迹及既定 M0 形式和支持网格；N/D 区间按计算结果为零宽度，没有人为放大，不覆盖模型形式或外部迁移不确定性。 |
| `q3-q-baseline-sensitivity.pdf` | 两组比较均固定在各自 $Q_0$；当前 M0 不含 $Q\to Loss$ 项，因此结果相同不代表质量提升效应或 $Q/p$ 联合优化结果。 |

`q1-share-loss-corr.pdf` 沿用附件已有图。其原始混合配比 CSV 当前缺失，故不建议在论文中声称本轮从原始样本重新计算了相关系数。
