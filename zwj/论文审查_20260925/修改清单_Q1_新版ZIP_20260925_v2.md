# Q1 修改清单｜新版 ZIP

审查对象为本次新版压缩包中的第 5 章。Q1 的整体顺序“问题分析—模型建立—模型求解—结果分析—验证/灵敏度—本章小结”清楚，三条建模线（质量评分、冲突度、配比—损失）均有方法、结果和边界。建议集中修改以下事项。

## 必须修正

### 1. 经验 $q_{95}$ 不保证样本中恰好有 5% 超阈

- **位置：** 5.2 冲突度定义附近，正文称“以 $q_{95}$ 作阈值意味着高冲突样本恒占 5%”。
- **问题：** 本文实际结果并非恒为 5%；A1 `book` 为 9/171=5.26%，A2 arxiv 为 4.47%，A3 github 为 5.14%。经验分位数给出阈值，离散有限样本实际有多少条超过阈值取决于样本量和取值分布。
- **建议替换：**

  > 本文将各来源域的经验第 95 百分位作为描述性高冲突阈值，名义上对应分布的上尾 5%；有限样本下，实际超阈比例不必恰为 5%。因此本文同时报告阈值、超阈条数和实际比例，不把该比例解释为经检验得到的真实冲突发生率。

### 2. 删除“book 阈值处并列记录”的解释

- **位置：** 5.4 冲突分析结果中解释 `book` 域 5.26% 的句子。
- **问题：** 论文称排序靠后的分位点“落在若干条并列记录上”；工作区 `domain_summary.csv` 的 `threshold_tie_rate` 为 0，结果没有阈值处并列记录的证据。
- **建议替换：**

  > `book` 域样本量为 171，线性插值的经验第 95 百分位阈值下共有 9 条记录超过阈值，实际比例为 9/171=5.26%。该比例与名义 5% 的差异来自有限样本下超阈条数只能取整数；结果文件未显示阈值处并列值。

## 表格需要补全口径

### 3. 在 `p+Q` 对照表中报告映射、候选和样本量

- **位置：** 5.2 表“加入质量特征前后的标准化 RMSE 对照”及其留出集变化表。
- **工作区口径：** 训练 OOF 使用 `direct_only` 映射、`q_huber_candidate`，并在三种模型共同有质量值的 478/512 条样本上比较；1M 和 60M 留出集各 248 条，1B 留出集 64 条。
- **问题：** 当前表没有显示映射版本、Q 候选或 (n)，读者难以理解为何 `p+Q` 比较的 OOF RMSE 与主模型全样本嵌套 OOF 指标不同，也无法判断留出集是否使用同一支持集。
- **建议：** 在表头或脚注注明 `direct_only`、`q_huber_candidate`、共同支持规则和每行 (n)。同时说明无 (Q_{mathrm{covered}}) 的记录不进入该三模型配对比较；不要把这组数字解释为使用完整训练集的泛化性能。

### 4. 解释二次面为何只是敏感性模型

- **位置：** 5.4 模型选择表及 5.5 灵敏度段。
- **数据事实：** 二次面嵌套 OOF 标准化 RMSE 0.58901，低于线性主模型 0.63305；同尺度 $R^2$ 为 0.6817，高于主模型 0.6189。正文称二次面不参与选模，理由是 153 个系数可能过拟合。
- **建议：** 说明把二次面排除在主模型候选族之外是否在评估结果前决定，并列出以参数复杂度/解释性为先的选择准则。如果没有预先确定，应在训练折内把二次面纳入嵌套模型族选择，再按选定模型报告；不要利用已经接触过的 A6–A11 留出表现二次挑选模型，也不要称其为新盲测。
