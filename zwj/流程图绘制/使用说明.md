# Q1 / Q2 / Q3 / Q4 流程图绘制说明

本目录包含六份可编辑的 HTML/SVG 源码，不包含最终 PNG 图片。

## 文件

- `Q1.1-flow-score.html`：Q1.1 建模与验证数据流。
- `Q1.2-flow-conflict.html`：Q1.2 冲突分析与污染敏感性流程。
- `Q1.3-flow-mixture.html`：Q1.3 配比—Loss 建模与验证流程。
- `Q2-flow-scaling.html`：Q2 标度律建模与证据门禁流程。
- `Q3-flow-resource-allocation.html`：Q3 固定 Q₀ 资源配置、稳健性分析与条件优化流程。
- `Q4-flow-capability-change.html`：Q4 能力指数、规模/时间分解与预测和桥接门控流程。

双击任一 HTML 文件即可在浏览器中查看。图形全部由内联 SVG 绘制，不依赖 Graphviz、Mermaid 或外部图片；文字、节点、颜色与箭头均可直接修改。

## 本轮统一样式

沿用原有 Q1.1、Q1.2 流程图的结构与视觉语言：

1. 页面和 SVG 不设置整体背景色，浏览器中呈默认白底，嵌入文档时保持透明；
2. 使用宋体风格中文、深色细边框、矩形步骤框、圆角汇总框和输入平行四边形；
3. 箭头以黑色直线或圆角正交折线为主，不使用阴影、渐变或装饰性外框；
4. HTML 内不嵌入图号、图题或外部范围说明，由论文中的 `\\caption{}` 统一管理，避免重复题注；
5. Q1.1 采用纵向主链与分叉汇合；Q1.2 保留横向主分析链和敏感性支路；Q1.3 展示配比模型与受限扩展的对照；Q2 区分 M0 基线和 p / Q 识别门禁；Q3 展示固定 Q₀ 下的离散资源筛选、稳健性分析与 Q/p 联合识别边界；Q4 并列呈现能力分解、前沿预测门和 Loss–Benchmark 桥接门。

根据审阅意见，颜色改用项目既有绘图代码中的 Okabe–Ito 色盲安全标准色值：

- 蓝 `#0072B2`：冻结数据和域级统计；
- 天蓝 `#56B4E9`：第二候选分支；
- 绿 `#009E73`：候选分、冲突度与同域复核；
- 黄橙 `#E69F00`：稳健性检验和组间比较；
- 朱红 `#D55E00`：Unicode 污染敏感性支路；
- 紫 `#CC79A7`：双人盲评与原文核验；
- 灰 `#68717B`：结构诊断和辅助线。

节点内部使用白色，SVG 与网页均不设置整体背景色。

## 修改方法

- 修改文字：搜索对应的 `<text>` 内容。
- 修改颜色：编辑 `<style>` 中 `:root` 下的颜色变量及 SVG 节点的 `fill` / `stroke`。
- 修改节点位置：调整对应 `<rect>` 或 `<path>` 的坐标。
- 修改箭头：调整连线 `<path>` 的 `d` 属性；当前转折线均使用圆角正交路径。

如需插入 Word，可在浏览器中按论文最终字号检查后再导出 SVG 或 PDF；HTML 文件应始终作为可编辑源文件保留。
