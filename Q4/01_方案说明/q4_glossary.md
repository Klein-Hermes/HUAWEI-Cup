# Q4 术语与符号表（暂定执行）

| 名称/符号 | 含义 | 单位或尺度 | 数据来源/限制 |
|---|---|---|---|
| `model_name_raw` | 来源记录的模型名 | 文本 | C1–C8 原文保留；不作为版本确认 |
| `version_unresolved` | 版本无法严格确认的名称候选状态 | 分类 | 当前 C1 缺 revision/SHA |
| \(N_i\) | 模型参数量 | 十亿参数（B） | C1 `#Params (B)`；不从名称补值 |
| `D_tokens_B` | 训练 token 数 | 十亿 token（B） | C5/C6；仅在来源记录支持时使用 |
| `Val_Loss` | 验证集交叉熵损失 | 原始单位 | C5/C6；必须逐项从来源核实单位与评测协议，未确认时不可换算 |
| `LB_Average` | 桥接表记录的汇总 Benchmark 分数 | 来源表原单位 | 不自动等同于 C1 `Average` 或六族指数 |
| `LB_*` | 桥接表内逐 Benchmark 家族的分数 | 来源表原单位 | C5/C6；需核对测试集及指标定义 |
| \(Y_i\) | 模型的六族相对能力指数 | 0–100 百分位点 | 六族内叶任务等权、族间等权；表达候选队列相对位置 |
| \(\boldsymbol{T}_i\) | 模型类型指示变量向量 | 0/1 | 来自 C1 Type 显式映射，不由名称推断 |
| \(m(i)\) | 模型的排行榜提交月份 | 年-月 | C1 `Submission Date`，不是发布日期 |
| \(\alpha\) | 规模/类型/月份线性描述模型截距 | 指数点 | 仅用于拟合值与分解；无独立因果解释 |
| \(\beta\) | 控制已列变量后的参数量关联系数 | 指数点/\(\log_{10}(B)\) | 描述性关联，不能解释为因果规模效应 |
| \(\boldsymbol{\theta}\) | 模型类型组系数向量 | 指数点 | 参照组为回归实际采用的基准类型 |
| \(\lambda_m\) | 提交月份固定项 | 指数点 | 混合未观测技术变化、队列选择和评测变化 |
| \(\varepsilon_i\) | 个体回归残差 | 指数点 | 观察值减拟合值；不等于单一遗漏因素 |
| \(P_{90}\) | 第 90 百分位数 | 对应指标原单位 | 每月明确开放权重新增模型的 C1 `Average` |
| \(F_t\) | 月度开放权重前沿指标 | C1 `Average` 原始分数 | 当月新增、C2 明确 Open Weights=Yes 模型的 P90 |
| \(a\) | AR(1) 动态模型截距 | C1 `Average` 分数 | 描述性时间序列参数 |
| \(\rho\) | AR(1) 一阶滞后系数 | 无量纲 | 前一期前沿与本期前沿的条件关联，不作因果解释 |
| \(u_t\) | 月度动态模型扰动 | C1 `Average` 分数 | AR(1) 未解释部分 |
| \(\Delta_{\mathrm{pred}}\) | 早晚期平均拟合能力差 | 六族指数点 | 由同一线性模型下的规模、类型、月份项相加得到 |
| \(x_i\) | 模型参数量的十进制对数 | \(\log_{10}(B)\) | \(N_i\) 以十亿参数计；用于规模/时间回归 |
| \(\bar{x}_g\) | 端点组平均参数量对数 | \(\log_{10}(B)\) | 仅在 P05–P95 共同支持样本中计算 |
| \(\bar{\boldsymbol{T}}_g\) | 端点组模型类型指示向量均值 | 0–1 比例向量 | 类型比例；仅在共同支持样本中计算 |
| \(\bar{\lambda}_g\) | 端点组月份固定项均值 | 指数点 | 来自共同支持回归；每个端点为单个月份 |
| \(\Delta_{\mathrm{size}}\) | 参数量分布组成项 | 六族指数点 | \(\beta\) 乘两期共同支持样本平均 \(\log_{10}(N)\) 差 |
| \(\Delta_{\mathrm{non\text{-}size}}\) | 非规模组成关联项 | 六族指数点 | 类型项与月份项之和；不是纯技术进步的因果贡献 |
| 共同支持区间 | 早晚端点各自线性插值 P05–P95 参数量区间的交集 | \(\log_{10}(B)\) | 回归月份需 n≥20；分解限于支持交集，空集则停止；不外推至尾部 |
| `ELIGIBLE_LIMITED_EXPLORATORY` | 预拟合门控允许进行受限探索拟合 | 分类状态 | 协议、量尺与目标支持已通过，但独立模型族不足以支持跨族校准 |
| `ELIGIBLE_FOR_CALIBRATION_VALIDATION` | 预拟合门控允许进入最低限度跨族验证 | 分类状态 | 仍不代表校准通过；须由拟合后的留一族验证给最终结论 |
| `SUPPORTED_FOR_CALIBRATION` | 拟合后的跨族校准支持结论 | 分类状态 | 仅在全部留一族预测有效且 MAE 不差于预定均值基线时使用 |
| 高可比 | Loss 与 Benchmark 来自相同模型/已核实版本及匹配评测协议 | 记录等级 | 以 C5/C6 `Loss_Comparability` 及逐行核验为准 |
| 非规模组成关联项 | 类型项与月份项之和 | 指数点 | 表示当前线性描述模型中的组成差异；不称为纯技术进步或因果贡献 |
| 训练计算量 | C4 的 `Training compute (FLOP)` 字段 | FLOP 或来源区间 | 只统计截至 2025-03-14 的记录；保留置信度、数值格式和估算方法；C4 未与 C1 个体匹配 |
| C3 年度背景序列 | C3 中 Open LLM Leaderboard 的年度数据 | 分数原单位 | 完整年趋势截止 2024 年；2025 仅作未满年度覆盖信息 |
