## 3. 动态能力模型与规模/非规模分解

### 3.1 动态模型

令 \(F_t\) 为第 2 节定义的月度开放权重前沿 P90（C1 `Average` 原量尺），只在连续且有观测的月份上估计一阶自回归描述模型：

\[
F_t = a + \rho F_{t-1} + u_t.
\]

这一定义将前一期能力水平显式放入本期方程，属于单变量动态模型；它只描述排行榜前沿的时间依赖，不代表因果机制。报告 \((a,\rho)\) 点估计与 HC3 区间（区间只对异方差稳健、不校正序列相关），样本月数和残差诊断；若残差仍有序列相关，区间只作描述，不作正式推断。另以扩展窗口的一步预测和持平基线比较 MAE：每个目标月的基线值固定为该训练窗口最后一个已观测前沿值。每个 AR(1) 回测训练窗口至少含 8 个连续月度观测，并满足设计满秩及至少 5 个残差自由度。完整序列只有连续月份不少于 8 个且设计矩阵满秩时才估计（至少 7 个转移、2 个系数、5 个残差自由度）；否则输出 `not_estimable`。无论是否能估计 AR(1)，年度预测仍须通过预测门：至少存在 3 个独立年度滚动起点，且回测 MAE 不高于持平基线 MAE；每个年度起点的基线均为该起点最后一个已观测前沿值，并在整个 12/24 月预测期保持不变。通过该门后才允许给数值年度外推及区间；否则保持不可可靠估计。小样本下模型系数只作动态描述，不据此宣称稳定预测能力。

### 3.2 规模与其他组成的精确账面分解

沿用六族指数 \(Y_i\)，在有共同支持的模型记录上拟合描述性线性模型：

\[
\widehat Y_i=\hat\alpha+\hat\beta x_i+\hat{\boldsymbol\theta}^{\mathsf T}\boldsymbol{T}_i+\hat\lambda_{m(i)},
\qquad x_i=\log_{10}(N_i\text{，单位为十亿参数}).
\]

尺度/时间回归的基础样本为完整六族指数、正参数量且有 C1 Submission Date 的记录；只纳入样本量不少于 20 的月份进行拟合，稀疏月份仅作描述。精确分解的早晚端点固定为 2024-11 与 2025-03，二者须为纳入回归的首末月份，否则停止分解。对两端点各自的 \(x_i\) 分布计算线性插值 P05 与 P95；共同支持区间定义为 \([\max(P05_E,P05_L),\min(P95_E,P95_L)]\)。若下界不小于上界则停止分解。最终分解回归仅使用所有样本量不少于 20 的月份中、且 \(x_i\) 落在此区间内的记录。该中心 90% 交集规则降低结果对端点参数量尾部观测的依赖；所得分解只描述该共同支持区间，不外推到被排除的尾部或完整候选总体。分位数采用线性插值。

令 \(g\in\{E,L\}\) 表示上述两个端点月份，\(\bar{x}_g\) 为端点组在共同支持样本中的平均 \(x\)，\(\bar{\boldsymbol{T}}_g\) 为该组类型指示变量向量的均值，\(\bar{\lambda}_g\) 为该组月份固定项的平均值。用共同支持样本上重新拟合的同一组系数定义两期预测均值差：

\[
\Delta_{\rm pred}=\hat\beta(\bar x_L-\bar x_E)
+\hat{\boldsymbol\theta}^{\mathsf T}(\bar{\boldsymbol T}_L-\bar{\boldsymbol T}_E)
+(\bar\lambda_L-\bar\lambda_E).
\]

因此规模组成项为第一项；非规模组成关联项严格定义为类型项与月份项之和；另分别列出类型项、月份项以及观测均值变化减去 \(\Delta_{\mathrm{pred}}\) 的算术闭合误差。规模、类型、月份三项按定义严格加总为预测均值差；不再使用未定义的 Shapley 反事实。基于同一个 HC3 协方差矩阵的线性对比区间适用于规模项、类型项、月份项、非规模合计及预测均值差；比较时固定早/晚期经验协变量分布，不将区间解释为抽样到更大模型总体的不确定性。观测均值变化另用共同支持端点的 HC3 两组均值差区间。因月份固定效应进入同一 OLS 且端点记录参与拟合，按正规方程观测均值差与预测均值差应相等；闭合误差只作点值和算术校验，不解释为未观测因素，也不对系数协方差构造区间。贡献占比为分量点估计除以观测变化的点比率，仅在观测变化、规模项和非规模合计的 95% 区间都不含 0 时报告，不另构造占比区间。

只有满足共同支持、两期各有正数记录、回归设计满秩且剩余自由度为正时才报告分解。贡献占比仅在总变化、规模项和非规模组成关联项的 95% 区间均不含 0 且共同支持成立时计算；否则只报告指数点和区间。参数系数与时间/类型项均为观察性关联，非规模组成关联项不能称为纯技术进步或因果贡献。

## 4. Loss–Benchmark 可行性门控（任何拟合之前）

预拟合门控脚本只读取、核对、去重并计算覆盖/支持统计，不拟合、不调参。它只判断是否允许进入后续建模分支，不提前宣称校准有效。每项保存原始行键、来源、审计状态和拒绝原因：

1. 核验 C5/C6 字段、原始单位、来源、Loss 与目标 Benchmark 是否均为有限数值；核验 `LB_Average` 与逐族 `LB_*` 的定义、量尺和测试集。
2. 以来源、模型标识、参数量、D、Loss 与所有 Benchmark 值组成内容键，识别 C5/C6 完全重复底层观测；重复只计一次。不同名称但不能确认版本的记录不合并。
3. 主要分析单位是独立模型族。逐行保留 `Loss_Comparability`、版本证据、验证集协议、目标指标定义和族标识；同一族的多尺寸模型可用于族内曲线，但不计作跨族独立验证。
4. 审计 Q1–Q3 中拟被转换的 Loss 来源、单位与实测目标支持范围。目标 Loss 不在通过核验的高可比样本范围内时，不允许靠模型外推生成桥接分数。C8 百分位指数不是 Benchmark 原始分数，不可直接作桥接响应。

预拟合门控状态唯一按以下规则决定：

- `BLOCKED_NO_FIT`：满足全部关键条件的高可比去重模型少于 3 个，或不同 Loss 值少于 3 个（不足以拟合含截距的一元线性关系并保留残差自由度）；或 Loss/Benchmark 单位、评测定义、目标来源任一无法核验；或目标 Loss 超出高可比实测范围。**不拟合。** 可查正式文献关系；若仍无可核验映射则报告不可桥接。
- `ELIGIBLE_LIMITED_EXPLORATORY`：上述单位、协议、目标来源及支持范围均通过，至少有 3 个不同 Loss 值的高可比去重模型，但独立可核验模型族少于 4 个。只允许拟合一个线性低自由度关系；只报告样本内探索结果，不报告可迁移校准误差或跨族置信区间。按模型族留一只作敏感性；模型行 bootstrap 不可替代跨族不确定性。
- `ELIGIBLE_FOR_CALIBRATION_VALIDATION`：至少有 4 个高可比去重模型且来自至少 4 个可核验独立模型族，目标 Loss 在实测范围内；并且对每个预定留一族训练折，训练集中有至少 3 个不同 Loss 值、设计矩阵满秩、测试 Loss 落在训练 Loss 范围内。此状态只允许进行最低限度线性拟合与留一族验证，**本身不等于支持校准**。

预拟合门控完成后，由 M1 审阅 CSV/报告及规则执行情况。只有 M1 通过且状态为两个 `ELIGIBLE_*` 之一，才运行相应最小拟合；P1 在该最小实现和留一验证后审查实现及数值。预先定义最终校准结论：对 `ELIGIBLE_FOR_CALIBRATION_VALIDATION`，所有留一族折都须产生有限预测，且汇总 LOFO MAE 不高于“各训练折目标均值预测”基线 MAE，才记为 `SUPPORTED_FOR_CALIBRATION`；否则降级为 `LIMITED_EXPLORATORY`，不声称迁移有效。任一必要折因奇异设计/缺少支持而无法估计时，不得记为支持校准。`ELIGIBLE_LIMITED_EXPLORATORY` 的结果保持探索性。若 `BLOCKED_NO_FIT`，拟合函数必须拒绝运行。

门控产物为 `q4_loss_benchmark_feasibility.csv` 与审计报告；最小模型实现/验证产物另存为 `q4_loss_benchmark_bridge_validation.csv`，不能把预拟合资格和最终校准状态合并成同一个阶段结论。

- C3 年度 Open LLM Leaderboard 表、C4 截止 2025-03-14 的训练算力/数据量/开放权重字段分别形成背景序列；它们不与 C1 进行无证据的个体级连接。算力增长情景只有在行级定义、时间戳与数值精度可核验时才作为估计输入；否则只能作为明确标注的条件假设，不提升预测可信度。
