# Q4 前沿预测模型方案 v0.1

## 目标

为原题的预测原点 2025-03 生成 2026-03（12 个月）及 2027-03（24 个月）的开源权重能力前沿条件预测。目标量严格沿用既有定义：每月新提交、C2 明确 `Open Weights=Yes` 的 C1 官方 `Average` 第 90 百分位，分值 0–100。

本方案是历史冻结包之后的独立续作；其条件情景输出受 `q4_task3_forecast_amendment_v0.8.md` 管理。它满足题目要求的三情景数值输出，但不覆写 v0.6 对可靠年度预测不可验证的结论。

## 预测模型

对截至 2025-03 的 C1 开放权重候选行，拟合原始 C1 `Average` 的横截面时间—规模模型：

\[
Y_i=\alpha+\beta_N\log_{10}(N_i)+\beta_t t_i+\boldsymbol\theta^\mathsf{T}T_i+\varepsilon_i,
\]

其中 (N_i) 是 C1 实测参数量（十亿参数），(t_i) 是自 2024-06 起的月份数，(T_i) 是 C1 原始 Type 映射后的类别指示变量。这里的响应变量是 C1 原始 `Average`，不是既有规模分解使用的六族相对百分位指数；因此不会把旧分解系数移植到前沿预测。

从最近观测前沿 (F_0=41.2745) 出发，在规模—时间模型的加性平移假设下，未来 (h) 个月的情景点为：

\[
\widehat F_{h,s}=F_0+h\widehat\beta_t+\widehat\beta_N\,\Delta\log_{10}N_{h,s},
\qquad \Delta\log_{10}N_{h,s}=\frac12\log_{10}\!\left(G_s^{h/12}\right).
\]

这一写法将未来月度前沿的分位数整体平移，隐含未来候选类型构成、残差分布和评分协议稳定；不是 C1/C4 个体配对所得的结构方程。

## C4 算力情景

使用 C4 年度训练算力 P90 的 2022–2024 对数线性增长率作参照情景锚点。三条未来路径为：

1. **历史速度延续：** C4 P90 算力按 2022–2024 对数趋势年化增长；
2. **中度放缓：** 年对数增长率减半；
3. **强放缓：** 未来算力 P90 不增长。

以 (N\propto C^{1/2}) 将算力路径转换成参数规模路径作为主规格，并用 (N\propto C^{0.73}) 作结构敏感性；这是外部 scaling-law 给出的两种不同制度/拟合下的情景指数，不是本项目估计值，也不是 C4 对 C1 的个体级估计。C4 只提供情景锚点；C4 的置信分类、年度样本数和字段口径一并输出。

这两个指数分别参考计算最优训练的 Chinchilla 结果（在论文设定下参数量与计算量满足平方根关系）及 Kaplan 等人的早期 scaling-law 估计（不同训练/拟合设定下指数约 0.73）。此处仅借用作结构情景范围，不声称任一关系已在 C1/C4 合并样本上得到验证。

## 候选模型与选择依据

- **持平基线：** 最近观测前沿作为预测值；现有 1 个月扩展窗口回测 MAE 为 0.757（5 个目标月）。
- **线性时间趋势：** 对月度前沿序列按时间拟合直线；现有 1 个月回测 MAE 为 3.596（5 个目标月），作为反例基线，不因其外推上升而优先选择。
- **AR(1)：** 月度前沿的一阶自回归；已有合格回测起点仅 2 个，MAE 0.821，不能据此支持年度技能。
- **规模—时间条件模型：** 上述直接以 C1 原始 `Average` 拟合的横截面模型，按三条 C4 情景生成 12/24 个月条件输出；其一步回测与冻结基准使用相同的 5 个可靠目标月，MAE 将在结果报告中给出。若弱于持平基线，仍仅作为题目要求的条件情景模型，不据此声称预测优越；年度技能仍未验证。

回测中的 C4 趋势必须按预测起点逐折估计：只可使用 2022 年起且在该起点之前已经完整结束的 C4 年份（年度截止为起点年份减 1）；不足两个年度点时，不为该折生成规模—时间+C4 预测。逐折使用年份和增速写入回测明细。最终 12/24 月情景仍按本方案前述定义使用 2022–2024 全部 C4 数据估计的情景参照增速，两者用途不同，不得混淆。

## 区间与验证

固定情景下的模拟分位数带以固定种子蒙特卡洛传播三项经验变异：月份簇 bootstrap 的 (\beta_N,\beta_t)；2025-03 前沿候选按模型发布者簇 bootstrap 的 (F_0)；最近 5 个持平基线一步误差中心化后作为未来逐月创新独立重抽样并累积。报告 2.5%–97.5% 模拟分位数。

模拟带明确依赖“近期一步创新可代表未来月创新、各月独立同分布”的假设；只有 5 个误差，且没有 12/24 个月滚动起点，故覆盖率未知。系数月份簇 bootstrap 与最新月前沿发布者簇 bootstrap 独立抽样，未传播两者协方差；它还固定 C4 路径和算力—参数指数，没有传播这两类假设不确定性。报告不能把它写成已校准的 95% 预测区间。

年度滚动起点数按同口径历史前沿计算。Open LLM Leaderboard v2 已于 2025-03 退役，v1 在 2024-06 被新版替代；两个版本的任务协议不能直接拼接。故续作提供题目要求的 12/24 个月条件情景与结构敏感性，但不宣称从现有附件得到可靠年度预测技能。v0.8 补充合同明确记录用户授权的有限范围变更。

目标队列的开放权重筛选沿用冻结数据表中的 C2 名称级 `Open Weights=Yes` 标签。若 `version_match_status` 未确认且无严格 revision/SHA 版本键，报告必须明确说明队列并非逐模型精确版本核验，预测只对该名称级筛选队列成立。
