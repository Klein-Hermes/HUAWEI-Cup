# Q4 Task 3 条件情景预测补充合同 v0.8

**生效范围：** 仅适用于本修订包中的“前沿预测模型 + C4 放缓情景”补充交付。它记录用户在 2026-09-26 明确要求继续完成题目 12/24 个月数值前沿预测后的范围变更；不改写冻结的 Q4 v0.6，也不把 v0.7 的历史判断伪装成已验证预测。

## 1. 对 v0.7 的有限覆盖

v0.7 对“从现有短序列能否得到可靠年度预测”的判断继续有效：同口径 C1 历史仅 10 个月，年度滚动起点为 0，因此年度预测技能未验证、覆盖率未知。

为满足题目明确要求的 12/24 个月定量输出，以及用户本轮“任务3：前沿预测模型 + C4 放缓情景”的明确指示，本补充**仅对条件情景交付**覆盖 v0.7 第 2 节“点值与区间留空”的报告规则：允许在明确写出情景与映射假设后输出数值点值和模拟分位数带。该授权不解锁“可靠年度预测”或“经校准 95% 预测区间”的表述。

## 2. 必须输出的内容

1. 预测原点为 2025-03；预测目标为 2026-03、2027-03。
2. 目标量为月度新提交、C2 标记开放权重模型的 C1 官方 `Average` 分数 P90（0–100），与六族相对百分位综合指数分开。
3. 至少输出 C4 算力历史增速延续、中度放缓（对数增速减半）、强放缓（算力持平）三种情景的点值；同时提供候选模型和现有一步回测结果。
4. 用“固定情景下模拟分位数带”命名 2.5%–97.5% 模拟分位数，不称其为已校准的 95% 预测区间。区间假设、训练样本、重抽样方法、未覆盖的不确定性必须随结果交付。
5. 主情景映射使用 \(N\propto C^{0.5}\)，并交付 \(N\propto C^{0.73}\) 的结构敏感性。两个指数都是给定假设，不是本项目识别得到的系数。

## 3. 结论标签和限制

- `conditional_scenario_only`：给定 C4 路径、算力—参数指数、候选构成和测评协议稳定假设下的数值外推。
- `annual_forecast_skill=NOT_VALIDATED`：年度同口径滚动起点为 0。
- `simulation_band_coverage=UNKNOWN`：模拟分位数带不具备经验证的覆盖率；不包含未来 C4 增速和映射指数的不确定性；系数 bootstrap 与起点前沿 bootstrap 独立抽样，未传播二者协方差。
- C4 年度 P90 仅 2022–2024 三点，记录置信等级混合，且 C4 与 C1 个体精确名称交集为 0；它只锚定情景路径，不识别 C1 的能力—算力关系。
- 评分协议与前沿总体不稳定：Open LLM Leaderboard v2 于 2025-03 退役，v1 于 2024-06 被新版替代。因此结果须同时说明外推目标沿用历史 C1 定义，不代表退役后的排行榜仍以相同口径更新。
- 若点值或模拟分位数越出 0–100，须保留原始外推并标记超界，不得静默截断；这意味着模型对该期限的分数尺度预测失效。
