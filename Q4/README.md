## 建议阅读顺序

1. 先看 [运行说明](05_审计交付/运行说明.md) 和 [任务操作清单](05_审计交付/任务操作清单.md)。
2. 核对 [输入合同](01_方案说明/q4_input_contract_v0.1.md) 与 [样本口径决策](01_方案说明/q4_cohort_decision.md)。
3. 从 [质量复核记录](05_审计交付/q4_quality_review.md) 查看现有结果边界，再浏览 `03_结果/results/` 与 `04_图表/`。
4. 冻结状态、授权记录和提交前披露余项见 [Q4 冻结包说明](05_审计交付/q4_freeze_package.md)、[冻结授权记录](05_审计交付/q4_freeze_approval.json) 和 [Q4 冻结前审计](05_审计交付/q4_prefreeze_audit_20260926.md)。
5. 写论文或更新旧交接资料前，先看 [Q4 当前问题收口说明](08_历史遗留问题收口_20260926/q4_current_status.md)，不要把 v0.6 的空预测表当成当前状态。
6. 净变化比率按估计对象区分：C8 六族指数 G4 结果仍不可识别；C1 Average 全窗提供规模/非规模最低限度描述性比率，及其近似区间和解释限制见 [Q4/09 补充报告](09_C1全窗占比补充_20260926/q4_minimum_c1_share_report.md)。

所有脚本、表格和图表均在上述目录内维护；原始题目附件保持只读。v0.6 冻结包和 06–09 补充修订应区分引用；补充修订完成独立复核和队伍审阅前不冻结。整篇论文仍须完成模板排版、W2 全稿复核和 AI 工具范围确认后才能作为提交稿。
