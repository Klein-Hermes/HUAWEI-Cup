# 问题一图表重绘代码

## 怎么跑

```bash
pip install matplotlib pandas numpy
cd figures/src
./run_all.sh              # 或逐个跑 python3 plot_q1_1.py
```

输出写到 `figures/`，每张图同时出 **PNG（600 dpi）** 与 **PDF（矢量）**。
论文里插的是 PDF（矢量在任何缩放下都清晰）。

换机器时改数据路径，两种方式：
```bash
Q1_DATA_ROOT=/path/to/HUAWEI-Cup/results ./run_all.sh
# 或直接改 style.py 顶部的 DATA_ROOT
```

## 设计依据

七篇往届优秀论文的图表实测规律（见 `guides/图表与命名规范.md`）：

1. **语义配色全文一致**——`style.py` 的 `C` 字典是唯一来源：
   蓝 = 本文方法 / 观测值，橙红 = 基线，绿 = 对照，灰虚线 = 基准线，琥珀 = 最优点。
2. **参考线 / 阈值线 / 置信带**——约 75% 的图都带一条。
3. **色标选型**：相关系数与关联系数 → `RdBu_r` 且 `vmin=-1, vmax=1`（以零为中心）；
   密度 → `viridis`。**禁用 jet**。
4. **极浅灰网格**（`#D9D9D9`）且在数据下方；去上右脊；**图内不加标题**——
   解释交给 LaTeX 题注。
5. **单图 3–4 维信息编码**（点大小 / 颜色 / 线宽 / 形状复用）。

**七篇的共同短板，本套刻意补上**：误差带与置信区间（全库仅 1 次文字提及）、
残差诊断（几乎无人做）、矢量输出（七篇基本是位图）。

## 图型替换说明

| 原图型 | 新图型 | 理由 |
|---|---|---|
| 域分柱状 | 带 95% 区间的误差棒 + 森林图 | 区间是这题的核心证据，柱状看不出来 |
| 冲突度折线 | 山脊图 | 7 个域的分布叠一张图，密度更高 |
| 跨尺度柱状 | 双轴图（RMSE 左轴 / Spearman 右轴） | 正文叙事正是"误差崩、秩相关稳"，一图讲完 |
| 模型选择柱状 | 哑铃图 | 三候选对比更适合哑铃 |
| 指标分布单箱线 | 横向箱线 + 方向着色 + 单位存疑标记 | 22 个指标一屏看完 |

## 新增的 3 张

1. **`q1-model-gain`** —— 主模型相对训练均值基线的 RMSE 改善（平均 37.4%）。
   原 15 张图里**没有任何一张展示配比模型的收益**，这是论证链缺口。
2. **`q1-conflict-effect`** —— 冲突度与评分分歧的关系。原图只报冲突度本身，
   未回答"冲突是否真的影响了评分"。
3. **`q1-substitution-volcano`** —— 替代效应的方向确定性。原图只给区间计数，
   未展示哪些方向在重抽样下稳定。

## 改配色 / 字号

只改 `style.py`：`C` 字典管配色，`setup()` 里的 `rcParams` 管字号与线宽。
改完全部 16 张图同步生效。

## 问题二、三的出图脚本（2026-09-24 新增）

| 脚本 | 产出 | 数据源 |
|---|---|---|
| `plot_q2.py` | `q2-m0-effect-{n,d,en,ed}.pdf/png` 四张 | `Q2/03_结果/经典ScalingLaw基线/v1/q2_m0_marginal_effects_by_{checkpoint,size}.csv` |
| `plot_q3.py` | `q3-{c7-lengths,frontier,cost-curve}.pdf/png` 三张 | `Q3/02_数据审计/C7_context_by_model.csv`、`Q3/04_结果/{M0_ND_reference_frontier,M0_budget_context_cost_shares,Q_cost_increment_envelope}.csv` |

两者都只**读取冻结产物**，不重拟合、不重抽样，被画的量全部直接来自 CSV。

一键重绘三问全部图表：`./run_all.sh`（需先 `chmod +x run_all.sh`）。

**为什么问题二的四张图是重绘的**：队员原图（`Q2/04_图表/q2_m0_effects/`）内容正确，
但用的是英文轴标签并带图内标题，与全文 18 张中文图不一致，也违反"图内无标题"的
规范。本脚本用同一份数据、同一批量重绘为统一风格。另有一处设计改动：原 ε_D 图是
2×4 分规模小倍图，而同一 $D$ 网格下八条曲线几乎重合（跨规模极差中位数仅 0.0100，
轨迹内沿 $D$ 的幅度达 0.1142），八个面板长得一模一样；改为与 ε_N 同构的点图 +
轨迹内 p10–p90 跨度，才能同时读出水平位移与轨迹内离散。

**数据根目录**：`plot_q2.py` / `plot_q3.py` 用 `style.DATA_ROOT` 的父目录定位团队
工作区（`<repo>/Q2/…`、`<repo>/Q3/…`）。换机器时设 `Q1_DATA_ROOT` 即可，两个脚本
无需改动。
