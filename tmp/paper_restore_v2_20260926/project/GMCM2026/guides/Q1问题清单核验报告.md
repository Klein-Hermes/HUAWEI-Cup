## 1. 高冲突率矛盾 —— 问题存在，已改

**核验**：清单指的位置准确。原文 L928 写着"表中 A1 各域的高冲突率**恒为** $0.0500$，
这是 $q_{95}$ 阈值的定义使然"，而同一张表（`tab:q1-conflict`）里 `book` 是 $0.0526$；
同一节稍后又写 `book` 是"唯一非 $0.05$ 的高冲突率"。**同一节内三处互相打架。**

**回源核对**（`results/q1_2_conflict_model/v1/domain_summary.csv`）：

| 域 | n | 高冲突率 | 超阈条数 |
|---|---:|---:|---:|
| arxiv | 1419 | 0.050035 | 71 |
| **book** | **171** | **0.052632** | **9** |
| c4 / commoncrawl / github / stackexchange / wikipedia | 10000 / 9640 / 10000 / 10000 / 10000 | 0.050000 | 500 / 482 / 500 / 500 / 500 |

清单说 `book` 是 9/171 —— **属实**。另发现一处清单没提的细节：`arxiv` 是 $0.050035$
（71/1419），也并非恰好 $0.05$，故改写时用"约 $5.00\%$"而非"恰为"。

**已改为**：说明阈值按各域经验第 95 百分位设定，样本充足的五个域恰为 5.00%，
`arxiv` 为 5.00%（71/1419），`book` 为 5.26%（9/171）；`book` 的偏离来自样本量——
171 条记录下经验分位数不保证超阈比例严格等于 5%，排序靠后的分位点落在并列记录上，
故有 9 条而非 8.55 条越界，属有限样本离散效应，不是阈值设定或数据异常。

## 2. 跨尺度结论边界 —— 问题不存在，不改

  与 `results/q1_3/v1/holdout_metrics.csv` 一致；

  **没有混入任何结果数字**。

**处置**：不改。清单要求的"摘要采用同一指标口径"记入待办——写摘要时锁死 closed 口径。

## 5. 压缩图表密度 —— 前提成立，不采纳

**前提核实**：Q1 确为 18 图 / 11 表 / 约 18 页，清单的观察准确。

**不采纳的理由**：

1. 清单自己写明"**不要据往届优秀论文推断本届存在特定页数上限**"——既然没有已知上限，
   压缩就没有明确收益；
2. 七篇国奖论文实测为 **68–116 页、25–50 张图**，本稿 70 页 / 35 图**并不超标**；
3. Q1 这 18 张里**没有成对重复图**（不像 Q2 的 `-n`/`-en` 与 `-d`/`-ed` 是同一批点的
   两种画法，那四张我已合并为两张）。Q1 的替代效应热图与方向确定性火山图、
   模型选型图与逐目标改善图，各自回答不同问题。

为压页数搬走支撑结论的证据，得不偿失。**不改。**
