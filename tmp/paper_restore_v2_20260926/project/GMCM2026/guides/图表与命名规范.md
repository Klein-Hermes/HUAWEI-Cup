# 图表与命名规范

> 目的：让全队出的图**看起来像一套**。后期统一改配色是最容易通宵的活，
> 提前定死，出图的人直接照规范出。
> 配色取自优秀论文的实测规律（5 篇横向比对）。

---

## 一、语义配色（全文统一，不破例）

> ★★ **唯一权威是 `figures/src/style.py` 里的 `C` 字典。** 本节与 `assets/gmcm.mplstyle`
> 都是它的镜像；三者数值不一致时**以 `style.py` 为准**。
> 出图前先 `import style as S`，用 `S.C["ours"]` 这种名字取色，**不要手抄十六进制**。
> （2026-09-24 修正：本节与 §七 原先残留一套 Flat UI 旧色 `#2E6DA4/#C0392B/#E67E22`，
> 与权威色系零重合，队员照抄后产出了离系统的图。已删除。）

**核心思想：颜色承载含义，不是装饰。** 同一个颜色全文只表示同一件事。
下表为 Okabe-Ito 色盲友好色系（`style.py` 的 `C` 字典）：

| 用途 | 变量名 | 十六进制 | 说明 |
|---|---|---|---|
| 本文方法 / 观测值 | `C["ours"]` | `#0072B2` | 蓝色，全文第一主色 |
| 基线 / 对照 | `C["base"]` | `#D55E00` | 橙红 |
| 第二对照 / 控制组 | `C["alt"]` | `#009E73` | 绿色 |
| 参考线 / 次要文本 | `C["ref"]` | `#8C8C8C` | 灰（虚线） |
| 异常 / 警示 | `C["warn"]` | `#B33A3A` | 暗红 |
| 最优点 / 高亮区间 | `C["hl"]` | `#E69F00` | 琥珀 |
| 第四组 | `C["purple"]` | `#CC79A7` | 紫 |
| 辅助 | `C["sky"]` | `#56B4E9` | 浅蓝 |

| 场景 | 色标 | 说明 |
|---|---|---|
| 相关系数（有正负） | `RdBu_r`，`vmin=-1, vmax=1` | 发散色，零为中心 |
| 顺序量（弱→强） | `viridis` | **禁用 jet** |

**反例**：一张图里颜色随机选、或同一含义在不同图里换色 → 评委看出是拼凑的。
**配色的连带一致性**：示意图（TikZ / 流程图）也必须用同一套语义色，
`paper.tex` 导言区已把 Okabe-Ito 定义为 `color1`–`color5` 与对应的浅色 `tint*`。

配套的 matplotlib 样式文件：`assets/gmcm.mplstyle`，用法见 §七。

## 二、图题命名

### 规则

```
图{章}-{序} + 空格 + 名词短语    6~18 字    【不带句号】
```

**正文里一律用 `\ref{}`，禁止手写"图5-3"**——改章节顺序后手写的必错。

```latex
\begin{figure}[htp!]
  \centering
  \includegraphics[width=.8\textwidth]{figures/q1-residual.png}
  \caption{残差结构分析图}      % ← 名词短语，不带句号
  \label{fig:q1-residual}        % ← 前缀 fig: + 问号 + 语义
\end{figure}

% 正文引用写法：
如图 \ref{fig:q1-residual} 所示，……   % ✓
如图 5-3 所示，……                      % ✗ 禁止手写
```

### 结果章的图题可以带结论倾向

优秀论文的做法——结果章的图题比过程章更长、更有信息量：

```
过程章：图4-4  8路链路均值相关性热力图
结果章：图5-5  堆叠模型校准总览：边际密度与联合密度对比
```

### 图后必须写一段（禁止"如图所示"四个字收尾）

```
看见什么 → 支持哪个判断 → 下一步因此做什么 → 不能推出什么
```

## 三、表题命名

### 规则

```
表{章}-{序} + 空格 + 内容     表题在表上方（模板已设置）
```

### ★ 尽量把数字写进表题

这是优秀论文的高频动作——让评委扫一眼目录就看到你的结论：

| 弱 | 强 |
|---|---|
| 表4-6 随机森林特征筛选结果 | 表4-6 随机森林筛得20个特征 |
| 表4-8 特征筛选结果 | 表4-8 筛选得到最终14个有效特征 |

### 括号补条件

```
表5-2  EESM 参数拟合结果（dB）
表7-2  三种模型性能指标（组内交叉验证时）
```

### 表格样式

- **三线表**（模板已加载 booktabs）：`\toprule` / `\midrule` / `\bottomrule`
- **无竖线**
- 表头加粗，居中
- 数字带单位
- 列类型已在 `paper.tex` 导言区定义好：`L`（左对齐伸缩）、`C`（居中伸缩）、`P{宽}`（定宽居中）

## 四、跨页表（符号表 / 大结果表）

用 **`longtable`**，不要用 `table`——`table` 是浮动体，超过一页会被**直接截断**。
模板里的符号表已经是 longtable 范式（含 `\endfirsthead` / `\endhead` / `\endlastfoot` 结构），
照抄即可。

## 五、图的排版策略

| 场景 | 做法 |
|---|---|
| 多子图对比 | `(a)(b)(c)` 横排，**图题里点明对照关系**（如"迁移前后对比"） |
| 多对象全套结果 | 同规格图 2 张一行平铺，**这是撑篇幅的主力**（优秀论文有 60 张这样的套图） |
| 大拼图 | 多方法 × 多样本的对比，用外部合成好的大图（列头写方法名、行标写样本号） |
| 整页图 | 技术路线图可单列一节独占整页（优秀论文的做法） |

**信息密度要求**：每张图 ≥ 2 个信息维度；过程图 : 结果图 ≈ 1 : 2。

### 图的放置宽度：多面板图用整幅 `\textwidth`

正文单栏宽度 469.47pt。**多面板图（≥4 面板或 ≥3 列分面）一律按 `\textwidth`
放置，不要用 `.92\textwidth`**——这一点是实测出来的，不是习惯问题。

2026-09-25 核对队友交付的 7 张补充图时量到：这些图按 7.2in 出图、图内字号
4.8–6.8pt，按 `.92\textwidth` 折算后 **57%–87% 的文字低于 6pt**（主流只有 5.6pt），
印出来读不清。改用整幅 `\textwidth` 后：

| 图 | `.92\textwidth` 下 <6pt | `\textwidth` 下 |
|---|---|---|
| `q3_p4_q_baseline_sensitivity` | 63.5% | 5.3% |
| `q3_p1_budget_nd_frontier` | 65.7% | 7.0% |
| `q3_p3_resource_shift_dashboard` | 57.1% | 11.5% |
| `q3_p2_bootstrap_selection_stability` | 80.7% | 14.6% |
| `q2_A_p_only_cross_scale` | 67.6% | 27.3% |

**验收判据（新图入库前必做）**：把 PDF 的 span 字号按实际放置宽度折算，
**主要文字 ≥6pt**，刻度与单位标注允许略低。折算系数 = 放置宽度 ÷ PDF 页宽。

### 中文字体：全文统一用宋体

`figures/src/style.py` 里 CJK 首选 `Songti SC`（宋），而队友的出图脚本首选
`SimHei`（黑）。**同一篇论文里宋黑混排看得出来**。新图入库前若字体不同，
要么让出图方改字体栈，要么由本方按同一份冻结数据重绘。
一张只画 2-3 条线的图 = 信息密度过低。

## 六、坐标轴与可读性

- 横纵轴**必须有标签和单位**
- 地图 / 三维图必须有**坐标、比例尺、图例、色标（colorbar）**
- 中文用宋体/黑体，负号用 `$-$` 而非连字符
- 每张图导出 **300 dpi 以上** PNG 或矢量 PDF（矢量优先，PDF 里放大不糊）
- 灰度打印可分辨（`gmcmthesis` 默认 `bwprint` 黑白模式，颜色要靠线型/标记区分）

## 七、`assets/gmcm.mplstyle` 用法

```python
import matplotlib.pyplot as plt

plt.style.use('assets/gmcm.mplstyle')   # 路径按需调整

# 语义色从权威来源取，不要手抄十六进制：
#   figures/src/style.py 里的 C 字典（本文件 §一 是它的镜像）
from style import C
plt.plot(x, y_true, color=C["ours"], marker='o', ls='',  label='实测')
plt.plot(x, y_base, color=C["base"], ls='--',            label='基准')
plt.plot(x, y_pred, color=C["alt"],  marker='s', ls='-', label='本文模型')
plt.legend()
plt.savefig('figures/q1-result.png', dpi=600, bbox_inches='tight')
```

出图后把图放进 `figures/`，文件名用**语义化命名**（`q1-residual.png`），
不要用 `图1.png` / `1.png` 这种——后期改编号会全乱。

论文正文里已有的出图脚本在 `figures/src/`（`plot_q1_*.py`、`plot_q2.py`、`plot_q3.py`），
统一 `import style as S`，可直接照抄其写法。
