## 二、数据章：写成「数据体检报告」

F 题那篇优秀论文的数据章只 4 页，但信息密度高，做法是：

1. **数据初检表**（每个数据文件的：记录数 / 字段数 / 缺失数 / 异常数）
2. **缺失值分类与成因分析**——按类型分类（如类型1机制性缺失、类型2随机缺失、类型3异常导致）
3. **缺失处理策略**：中位数填充 / 线性插值 / K-邻近扩散，**每种都要说为什么选它**
4. **异常值处理**：统计阈值法 + 领域校验法（双管齐下）

## 三、模型建立：本类题的核心是「指标可计算化」

主观概念（美学、舒适度、公平性、质量）转成可计算代理指标：

```
主观概念 → 分解为若干维度 → 每个维度给可计算代理 → 组合成综合指标
```

三条硬性要求：

1. **每个代理指标都要论证与主观感受的对应关系**
   （理论应然关系 + 学界共识互证，因为这类题外部真值稀缺）
2. **"过与不及都扣分"的量用核函数/区间表达**（如适量度用高斯核）
3. **权重必须附「依据列」**（AHP / 熵权 / CRITIC / 组合赋权）
   > ★ 优秀范文被点名表扬的亮点就是"权重表附依据列"——每个权重为什么是这个值
   > ⚠ 反例：权重拍脑袋无依据列

## 四、`模型验证与灵敏度分析` 节：F 题最该发力处

参照 116 页优秀论文的做法（每问章末独立一节，各 3-6 页）：

**用「四列验证表」**：`指标名 / 具体结果 / 评估标准 / 评估结论`

```
例：开合度计算相对误差(MRE) | 0.0364 | MRE<0.08 | 优秀
```

要点：

1. **判据必须预先给出再对照**，不能只丢一个数让评委猜好坏
2. **不同问用不同验证指标时，主动说明"为什么换"**
   （优秀范文原话式："本问题与问题1的绝对误差不同，该指标使用相对误差来评估……更适用于不同尺度的对象"）
   —— 这体现方法论自觉，是很强的加分动作
3. **可引入多范式验证**：连续量误差(MRE/MSE) + 分类一致性(Kappa) + 频域相似(Coherence) + 聚类一致性(ARI)
4. **交叉验证 + 学习曲线**，并**主动承认过拟合**（"训练分数与测试分数存在 gap，但测试集持续走高，表明未严重过拟合"）
5. **敏感性分析**：承认参数是主观给的 → 换几组权重对照 → 折线图 + 热力图 + 雷达图 → 结论"整体稳健且有偏好调参空间"

## 五、结果分析的两个特殊要求

1. **区分度检查**（本类题最容易翻车处）
   反例：高维余弦相似度饱和到 0.986、45 对全部 >0.85 → 无区分度，不能下排序结论
   正例：20 维融合后落在 0.52-0.85 → 有区分度
   **交付前必须检查：所有方案得分是否挤在窄区间？挤了就不能排序。**

2. **把数字翻译回领域语言**
   优秀论文在结果分析里写 300-600 字的领域解读（把数字翻成专业术语），
   这证明作者懂题而不是套公式，是本类题的重要加分项。
